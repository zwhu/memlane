# Memlane 桌面 UI 编写与视觉自检护栏（`app/`）

详细页面规格见 [V4 视觉与交互规范](../docs/design/visual-standards-v4-20261120.md) 与 [动效契约](../docs/design/motion-implementation.md)。改动 `app/` 或 `kit/ui/` 时必须先遵守以下 5 条硬约束：

1. **布局与信息降噪**：严禁大框套小框、嵌套卡片与多余分割线；能靠标题、对齐与留白自解释时，禁止堆砌标语、副标题和解释性描述文字。
2. **令牌与配色唯一源**：严禁在 `app/` 直接写 `ui.Hex`、`ui.RGBA`（`brand_icons/` 除外）或 `.Bold()`（700 字重）；全部复用 `kit/ui` 的 `Tokens`（中性灰阶 + 单一 `Accent`）、`FontUI`/`FontMono`、`FS*` 字号与显式 `400/500/600` 字重。
3. **4px 网格与图标规范**：所有 `Padding`、`Gap`、`Margin` 严格使用 `kit/ui` 的 4px 整数倍令牌（`Sp1`–`Sp10`，仅 `Gap(1).Dividers(1, ...)` 分隔线槽与规范显式例外除外）；图标统一使用 `kit/ui` 24×24 画框与 `1.5px` 线宽原语。
4. **交互克制与防误触**：列表/卡片中的次要操作按意图显露（默认隐藏，Hover/Focus 显现）；悬停浮层与多级菜单统一使用 `kit/ui.HoverIntent`（开启延时 + 关闭延时 + 安全三角），严禁手写裸轮询。
5. **真实渲染验收**：禁止只凭代码属性或单测通过交差——UI 改动必须检查浅色与深色 `1200×820` 渲染图，逐项核对 **① 对齐、② 意外换行与截断、③ 留白节奏、④ 遮挡与双外观对比度**。
