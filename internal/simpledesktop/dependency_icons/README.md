# 依赖品牌图标

原始 SVG 本地随 UI 使用，运行时不请求网络。品牌归各自所有者；未重新绘制或改变颜色。

- Python：CPython v3.12.12 的 `PC/icons/logo.svg`，https://github.com/python/cpython/blob/v3.12.12/PC/icons/logo.svg
- Cognee：固定 ec6f408 归档中的 `cognee-frontend/public/visuals/logos/cognee.svg`，https://github.com/topoteretes/cognee/blob/ec6f40859e5f2df9e7862dde27d580ac3268ed43/cognee-frontend/public/visuals/logos/cognee.svg
- uv：官方 0.12.3 的 `docs/assets/logo-letter.svg`，https://github.com/astral-sh/uv/blob/0.12.3/docs/assets/logo-letter.svg
- Hugging Face：官方品牌 SVG，https://huggingface.co/front/assets/huggingface_logo-noborder.svg ，表示模型分发来源。具体模型和 revision 仍由安装清单确定。

“运行库”是依赖集合，使用已有通用组件图标，不冒充单一品牌。
