# P3-I 引导与初始化契约

2026-11-08，I 本机实现与pi/App/Rust验收已通过，详见 [验证](../../../p3-onboarding-validation.md)；A/R/G/F及正式分发仍未完成。首次打开直接进入宽幅首页；引导可跳过并从设置恢复，步骤完成不由复制 prompt 或用户勾选冒充接口回执。

## 引导状态

组件准备以实际清单/校验/worker健康为准；项目以登记 scope/仓库身份为准；Agent 分别显示发现、待连接、待重载、可用与错误。连接成功沿用已验证通道的真实工具回执。初始化可选，不阻塞普通用户新增、搜索、编辑或连接 Agent。

用户偏好只保存是否隐藏/继续引导；每次重新打开依实际状态刷新。组件或连接后来失效时不继续标记可用。首次离线且没有组件明确需要联网；已准备本地索引不依赖云模型。初始化模型沿用 Agent 自己的认证与选择，客户端不自动发起收费初始化。

## 可复制 prompt 与提交

用户在App明确选择已登记项目、连接和1–16个仓库内普通文本材料路径，合计最多128KiB；不自动遍历仓库。只读取所选代码/文档，排除Git与Agent配置、数据库、聊天日志目录及外部软链接，保存具体文件路径、SHA256和原文快照。文件读取在SQLite事务外进行。App 提供指向用户选定项目的 prompt，要求用户在自己的 Agent 执行：先核对实际工作区和已授权 scope，只整理当前仓库代码、文档及用户明确提供的材料，不读取聊天库；提取少量清晰项目约定，附具体出处，遇到冲突/来源不足说明不确定，不覆盖已有有效知识。

复制只代表生成文本，界面仍显示等待实际提交。prompt 不含登录凭据、连接秘密或生产数据库路径，不指示安装/升级 Agent。老通道不支持批次工具时明确待支持，不能把多次普通保存推断成初始化成功。

正式批次最小1条、最大16条，合计不超过128KiB，沿用已确认来源/输入资源上限。只接收新增知识，原始工具轨迹仍走已有 raw 保存入口。每条有项目内稳定标识、标题/正文和对已批准文件快照的精确引用/摘录；宿主校验文件路径、SHA256与quote匹配，记录导入时的具体文件版本。提交前复查材料，检测到变化则过期并重新准备；保存后的出处仍是导入时快照，不承诺工作目录永不变化。每条同时保留 Agent 身份；不以摘要或同源转述构造独立证据。

App 复制前登记一个等待提交的持久批次，绑定所选项目、Agent连接/代次和受信工作区；此记录不是导入成功，不自动调用模型。未提交批次可取消，取消后迟到提交拒绝；提交先于取消则回传已保存事实。prompt包含非秘密批次ID，Agent用受控工具提交，不传生产DB路径。批次绑定稳定 operation/batch ID、project、连接/代次和真实工作区；同请求重放返回原回执，不同内容复用 ID 冲突。新的初始化知识按 imported 来源记录，在实际收录时生成导入事实；不造原作者历史日期，也不增加当天新知识热力图。项目内初始化条目标识跨批次/连接去重；新批次遇已有相同标识拒绝整批，不能重建、覆盖或恢复旧知识。已有知识同 ID 或需要覆盖时拒绝自动改写，进入既有用户审核规则。

## 事务、失败与取消

验证整批输入和范围后一次短事务提交新增版本、来源、幂等批次回执和索引任务；不持事务等待模型或网络。非法输入/SQL失败整批回滚，App 保留失败与可重试提示。索引独立完成，已接收/已保存/可检索分开；索引失败保留知识与回执并支持恢复。

取消先于提交则不导入；提交先于取消则保留已提交事实，不能声称删除或撤回。稳定批次回执跨重启保留。重复调用不重复增加导入/活动次数，也不通过恢复回填历史。

初始化Agent只通过受控批次查询/提交入口获得已批准快照并返回结构化新增项；隔离验收不授予文件/命令/普通保存或批准工具，不给生产数据库句柄。日常用户在自己的Agent执行复制prompt，工具不支持时必须报告不可用，不能用普通保存回填为初始化成功。

客户端状态只基于实际批次/索引回执：尚未提交、失败、取消、已接收等待索引、部分索引失败、可检索。普通连接验证不代表初始化；初始化导入数与日常新知识数分开展示。
