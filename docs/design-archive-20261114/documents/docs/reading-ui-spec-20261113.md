# UI 优化规格：知识标题、正文与出处

日期：2026-11-13。状态：已启动dev实施；逐项证据及RU-G真实搜索阻塞见[执行记录](engineering/reading-ui-execution-20261113.md)，尚未全部验收。配套：[产品方案](reading-ui-product-plan-20261113.md)、[技术方案](reading-ui-technical-plan-20261113.md)。

## 展示规则

| 编号 | 规则与完成标准 |
| --- | --- |
| RU01 | 可读 label 优先，其次可读文档名称；`text_<32位十六进制>`等明确机器名不作标题；未知名称不随意丢弃 |
| RU02 | 无可读标题自动读取当前页正文，清理已确认包装后取首个非空正文段的首句，最多80个Unicode字符；不按字节切割 |
| RU03 | 获取前显示“知识 · YYYY-MM-DD”，日期未知显示“知识”；单条失败显示简短读取提示并可单条重试，不暴露hash作标题 |
| RU04 | 详情和列表标题一致；标题补全不重排列表、不改变计数、选中、滚动或当前页，不要求用户逐条点击 |
| RU05 | 仅在官方知识类型、唯一来源session和固定正文包装一致时移除包装；冲突或未知模板保留原文并说明未清理，不通用删除任意标题或元数据行 |
| RU06 | 主阅读区域不显示 dataset/document UUID、生成文件名和机器session标题；完整字段放默认折叠技术详情，允许复制 |
| RU07 | 正文 Markdown、代码、链接、语言、事实和顺序保持；不翻译、不调用模型生成标题、不改官方存储 |
| RU08 | 出处显示“来源会话”及可核实的时间；已有可信会话标题可使用，无日期不编造；来源跳转沿用真实ID与逐层返回 |
| RU09 | “复制知识内容”复制可见清理后正文；“复制原文”提供原始文本；未知模板二者均保留原文 |
| RU10 | 切项目／分页／搜索条件／官方服务身份时取消过期标题请求，迟到结果不得覆盖新对象 |
| RU11 | 401/403/404或来源身份失效时撤下相应正文、缓存和复制入口；网络超时保留上次仍有效显示并提示，禁止错写为成功 |
| RU12 | 普通知识列表、详情、全局搜索及已有最近知识入口复用同一展示规则；搜索片段保留片段语义，不伪装完整知识 |

## 状态

每条标题为 pending／ready／failed／unavailable；不新增整页加载遮罩。技术详情独立折叠状态随对象保存，刷新不因标题更新重置。首次列表空与获取标题失败分别表达。

补全后台最多并行4个当前页 raw请求；每个请求15秒超时，单页30条；切页取消。成功结果仅在本进程有限缓存，重新进入时先核对官方版本再复用。自动补全失败不循环重试；手动刷新／单条重试重新读取。

## 范围与视觉基线

本 session 用户截图为具体问题证据；当前[三栏稿](images/ui-redesign/client-simplification-20261112/02-knowledge.png)和[首页稿](images/ui-redesign/client-simplification-20261112/01-home.png)已实际查看。只改变阅读信息层级，不恢复窄窗、编辑／删除等按钮，不修改总览统计和图谱。

英文首句可能较长，列表单行截断显示，详情允许自然换行；不得为追求中文短标题另加模型任务。正文代码横滚、问答／工具折叠与返回位置不回归。

## 连续验收

- RU-A：截图同类的hash名称知识 → 打开项目列表 → 无需点击，各条自动得到内容标题 → 选中后正文已清理、列表详情一致。
- RU-B：可读label、空正文、英文长句、中文、代码开头、重复首句和未知模板 → 按优先级呈现，不编造概括、不误删内容。
- RU-C：部分 raw超时、403、404 → 对应状态和缓存失效正确，其他行可读，列表计数不归零。
- RU-D：标题读取期间切项目／分页／搜索 → 旧回执不污染新页面；后台刷新保持正文、选择、工具及滚动。
- RU-E：展开技术详情 → 复制原文／ID → 折叠 → 复制可见正文 → 来源会话 → 逐层返回；原始内容、复制结果和返回栈分别正确。
- RU-F：官方更新／替换同ID或服务身份改变 → 不复用旧缓存；1000条库只读当前页缺标题正文，不全库扫描。
- RU-G：最近知识和搜索片段进入详情、来源、返回 → 同一身份标题一致，片段不被误写为全文。

局部函数与HTTP夹具、真实官方只读和Native1200×820分别留证；启动后的实际结果见执行记录，不将夹具等同全部真实场景。同一问题失败计数沿原记录，第4次仍失败停止。
