# 项目权限管理产品方案

日期：2026-11-13。状态：按本 session 整理的产品提案，未实施、未做运行验收。配套：[规格](project-access-spec-20261113.md)、[技术方案](project-access-technical-plan-20261113.md)。

## 目标与范围

用户在 item-fe 等新仓库正常使用已连接 Agent，即可自动积累并在 Memlane 阅读知识；用户也能控制具体 Agent 的项目读写、自动采集与处理。项目自动同步、新建／关联、项目权限与通用知识管理归入同一条项目管理流程。

另一部分[UI 优化](reading-ui-product-plan-20261113.md)只负责知识阅读展示。总览统计、热力图和近期动态由另一 session 的[总览方案](overview-product-plan-20261113.md)负责，不纳入本部分。

## 对话已确认的决定

- 新项目默认自动接入，不要求用户先添加项目或逐项目授权。
- 用户一次设置新项目默认策略，新项目自动继承；具体项目可以覆盖默认值。
- 权限包含不同 Agent 的项目读写范围，以及自动采集、自动处理控制。
- Cognee 已有 dataset 级权限；复用官方能力并接入管理界面，不把它描述为底层能力缺失。
- 新建／关联项目与自动发现一起设计；通用知识独立管理，供跨项目使用。
- 禁写后是跳过还是报错必须在技术方案查清；详见配套方案的源码事实与目标行为，不用待研究占位。

本需求覆盖旧版不设计项目权限的后续产品方向，但未授权恢复旧实现或启动本轮开发。

## 产品主流程

一次配置新项目默认规则 → 在新仓库正常编码 → 自动识别并建立项目关联 → 自动应用对应 Agent 权限 → 按规则采集、处理 → 桌面自动显示项目及内容 → 后续会话召回使用。

发现项目与允许内容写入分开执行。默认模板禁写时，项目仍可以出现；自动采集不提交新正文，也不反复报错干扰编码。用户主动保存时则收到清楚的无写权限结果。

## 本方案给出的产品选择

下表是为使方案可实施而给出的明确提案，不冒充用户逐项确认；评审可修改，技术与验收均按同一版规则执行。

| 事项 | 本版选择 |
| --- | --- |
| 新项目初始模板 | 已连接且受 Memlane 管理的 Agent 默认可读、可写并维护知识；自动采集和自动处理开启；用户可先修改模板 |
| 修改默认模板 | 更新所有仍使用默认值的字段；已有项目明确覆盖的字段保持不变；保存前展示影响范围，保存后报告实际生效状态 |
| 写权限语义 | 界面明确“可写并维护知识”，包含官方自动整理需要的替换／删除能力，不称“只可新增、禁止删除” |
| 自动行为与手动操作 | 自动采集／处理开关只控制自动行为；主动保存和手动处理仍检查相应官方权限 |
| 禁写 | 自动采集在读取新正文前跳过；主动保存明确提示；旧待发材料阻塞并暂停重试，不在重新授权后偷偷补交 |
| 新加入 Agent | 连接时显示会采用的新项目及已有继承项目规则；连接完成后纳入默认模板，不越过具体项目覆盖 |
| 会话归属 | 新会话按仓库绑定；临时 cd 不切项目，已有会话不静默迁移 |
| 通用知识 | 独立数据集，已连接受管 Agent 默认只读，桌面用户管理内容；不自动提升项目知识 |

写入能力包含删除的原因：固定官方 coding-memory 整理会删除同状态键的被替换知识，需要 write 和 delete；最小成本方案复用这一行为。其技术权限也允许直接调用该数据集的删除接口，不能承诺只允许删除自动生成条目。产品界面必须说明这一含义；如果要求“可写但绝对不可删”，属于另一套执行身份拆分方案，不在本版偷加。

## 页面和操作

- 设置 → 项目默认规则：选择 Agent 访问级别，配置自动采集／处理；展示继承范围与保存结果。
- 项目 → 项目设置：显示来自默认规则还是本项目覆盖，可逐字段改写或恢复默认；显示权限同步中／已生效／未确认。
- 项目列表 → 新建／关联：选择本机仓库或已有官方数据集，显示可理解的名称；不要求手输 UUID。
- 通用知识：个人偏好／通用经验分类，阅读、搜索、新增、编辑、删除；保留适用条件和来源。

权限状态使用产品用语，不展示角色、principal、token 等实现字段。连接认证和实际权限生效是不同事实；保存配置后尚未同步成功不能显示已生效。

## 边界与交付

不开发远程管理、账号协作平台、审批流程、全文版本库或内容副本。知识和原始材料仍属于 Cognee；代码图按项目显式开启。关闭窗口保持后台，电脑重启按现有 dev 入口手动启动，不进入 release。

原 memlane 及 item-fe 会话和数据保留，不因接入新权限自动搬移、删除、补采或重放。运行中的其他 session 不被本轮文档影响。

详细技术方案已给出默认值、继承算法、路由位置、禁写处理及组件职责；运行测试、真实模型和 Native 验收仍属于实施后的证据，当前未报告通过。
