# 通用知识重设计与实施

2026-11-14，用户明确要求“通用知识重新设计并实现”。范围：通用知识分类列表、阅读、紧凑编辑、保存／处理核对及删除确认的呈现；沿用官方CRUD、版本摘要、权限与未知结果处理，不新增知识引擎／索引／模型方案。默认1200×820、放大1440×900，不做窄窗。

本轮使用plan-change-impact和verify-continuous-scenarios。开发前源码干净，7份无关未跟踪文档保留；设计沿用已确定的浅蓝导航、220/300/余宽三栏及顶栏统一搜索。基线即本记录提交与注释tag，后续填写。

## 影响与先后

共用导航／统一搜索／项目页保留；通用知识从旧reading分支移到独立页面。复用CommonDraft、writeCommon、confirmCommon、deleteCommon及现有编辑前摘要核对；请求未知后不重发。先固定三栏、阅读和编辑状态规则，直接用生产组件及人工数据生成标注预览，再核对HTTP与UI连续流程，避免再开发CSS原型。

## 预列场景

- C01：分类切换／分页／刷新／选择，已载入、真空、首次加载与失败保留区分。
- C02：新增→输入分类／标题／正文→补充条件及来源→保存，忙碌防重复，提交后锁定，核对原保存。
- C03：阅读→编辑→返回阅读→继续编辑，草稿保留；分类／来源在编辑既有知识时锁定；正文原摘要变动拒绝覆盖。
- C04：保存和处理状态分别表达；未知结果只核对，不再提交；切页不把迟到回执应用到另一草稿。
- C05：阅读复制／信息、删除展开→保留／确认；先确认具体条目，成功后撤下旧正文，失败不伪装成功。
- C06：统一搜索、项目页、首页回归；权限或对象失效撤下编辑、阅读及复制。
- C07：两尺寸人工夹具与标注图；实际HP外接屏验收另记，当前系统仅内建屏在线，尚未获改用内建屏的回复，不操作实际窗口。

沿用PR/AN/E/PA既有失败计数；本轮尚未执行验收，不能把页面重设计重置为零。第四次同一具体问题失败停止。
