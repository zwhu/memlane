# 项目记忆的三种浏览视图

2026-11-08。用户确认 A／B／C 都需要，保留为同一个项目下的「记忆」「实体」「关系图」三个视图，而不是三选一。本文记录已确认的浏览结构与当前原型；不恢复暂停的全量工程 Goal，不选择日常自动保存策略。

## 共同范围与数据

三个视图使用同一项目、同一批记忆和来源关系。切换视图不创建新项目、新数据集或新记忆。

- 项目是仓库、数据归属与访问授权的范围。
- 记忆视图展示可阅读的知识正文与出处；原始记录单独查看，不计为新增知识。
- 实体是记忆中涉及的对象，例如函数、类型、文件或工具。实体计数按身份去重，不按文档数或提及次数计算。
- 关系图展示记忆涉及哪些实体，以及实体之间的具体关系。记忆—实体的来源关联和抽取的实体关系用不同线型表达。

本轮真实合成材料有两条已导入记忆、六条原始记录，两份文档关联十三个 Entity。原始记录与关联读取本轮隔离材料，原文不提交到仓库。正式 App 的三视图、完整阅读器和受信实体读取代码已实施，真实图与本轮连续正常任务尚待验收；原文导入和 Rust 索引的历史基线仍保留。

## 三个视图

| 视图 | 用来回答的问题 | 主要内容 |
| --- | --- | --- |
| 记忆（A） | 这个项目积累了什么？这条约定具体是什么？ | 记忆列表、正文、涉及对象、来源入口 |
| 实体（B） | 关于这个函数、类型或文件，有哪些记忆？ | 实体筛选、相关记忆、阅读与快速查看入口 |
| 关系图（C） | 这些对象和记忆如何关联？ | 可点选图、关系标签、记忆或实体详情 |

三个入口并列在项目页顶部。项目标题、仓库与数量保持稳定；主内容区随视图切换，不把底层 dataset／session／长 ID 作为主要浏览内容。

## 相互导航

- 在记忆中选择实体，可跳到实体视图查看所有相关记忆，或在关系图中定位。
- 从实体找到记忆，可在记忆视图打开，或用右侧页快速查看。
- 在关系图中点记忆，显示对应正文；点实体，显示相关记忆，并可进入实体视图。
- 切换视图保留当前项目、记忆和相关实体。当前记忆变更时，关系图同步显示该记忆的局部关系，不能保留上一条记忆的图并冒充新结果。
- 切换项目关闭当前临时详情，使用新项目范围；再次返回时恢复该项目的浏览位置。没有已导入材料的项目显示真实空状态。

当前原型用 URL 表达视图、项目、选中记忆与实体，重载和浏览器返回可恢复上下文。正式实现需以服务返回的稳定身份与具体版本维持选择，不能以标题猜关联。

## 原始记录阅读器

原始记录从记忆出处打开，统一展示项目、当前记忆、具体来源版本，以及完整问答／工具结果。

用户已明确允许原始记录使用弹框或右侧完整页面。本轮原型提供侧页、弹框、整页三种阅读方式；切换阅读方式保留正在阅读的来源记录。原型初始用侧页，该初始值不单独视为最终产品默认决策。

阅读器中只读查看，技术标识按需展开。原项目的原始记录不会因查看或切换视图变成新知识，也不会因全局经验关联而自动向未授权消费者公开。原文与提炼出现差异时分别保留，不改写出处掩盖差异。
