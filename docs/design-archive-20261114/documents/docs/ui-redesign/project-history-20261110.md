## 已实现的范围和所有者

- 初始化仍只有三步。历史选项只出现在日常项目整理右栏；打开页面不扫描历史，勾选「同时整理历史会话」才调用要求明确确认的正式服务目录接口。
- 目录固定于当前已验证Codex安装的配置目录，不接受UI或模型提供任意日志路径。检查连接ID、代次、工具集、安装回执、配置块和当前项目授权；只适配已验证的 `codex-cli 0.167.0-alpha.3.2`。
- 对其他仓库只检查会话元数据，不读取聊天正文。当前项目以canonical cwd、Git common目录及其实际文件身份核对，同仓库worktree按同一项目归属；元数据／turn上下文的多个工作根也必须属于同仓库。混合项目、无法确认归属、重复会话标识、符号链接及不支持来源不作为可选完成会话。
- 目录按20项分页，读取完整目录后选择其中可读取的已完成会话。固定稿的单个勾选表示选择当前Agent／项目的这一组会话；界面显示真实选中数量、不可读取／无法归属数量，切换绑定清除选择，历史增加用量的提示保留。无记录与读取失败分开；没有可选会话时可取消勾选后只整理仓库。
- schema21只新增不可变 `project_task_histories`。启动前重新核对所选原日志SHA256、会话身份、项目和当前绑定，将来源正文与元数据同任务／尝试一起冻结。项目在选择后变化时拒绝启动；启动后使用已冻结版本，不把后续文件变化替换进运行任务。
- 恢复相同启动意图读取已存在的正式任务，不为恢复回执重新读取现在的日志或执行模型。原任务范围、尝试及版本不因查看知识、关闭右栏或切页改变。
- 模型仍使用绑定Codex当前模型与正常仓库只读工具。`memlane_project_history`只接受已选会话标识，由daemon的活跃任务所有者读取；未知会话、错误尝试、取消、撤权或仓库替换时拒绝。先读当前知识，再读取选定会话；所有选定历史的工具响应都已发送才释放最终候选。没有新增也不能跳过选定历史后声称完成。
- 历史正文保留用户、助手和支持的工具请求／返回及各自消息时间，排除开发者／系统指令、内部推理与运行上下文。非文本消息、未知工具返回形式、未完成的最新任务或超限均明确不可用，不截断后冒充完整。支持当前普通cli／exec／vscode／appServer来源；其他Agent、旧版本、归档目录及迁移日志的完整矩阵仍待补。
- 历史源使用独立 `source_detail.history`，保留Agent、会话、工作区、CLI版本、原始时间和选中原日志摘要，与仓库出处、Cognee instance／dataset及官方trace分开。普通Agent保存不能伪造这个由C所有者签发的来源字段。
- 新知识实际引用历史时，才按正式知识／原始记录保存规则形成来源与精确引文。原会话时间不被本次整理时间替换，也不回填虚构旧活动；新知识的保存与索引仍分阶段记录，不自动改写已有有效知识。

每个日志最多16MiB，提取的完整文本来源最多4MiB，任务仓库与历史来源合计32MiB；超过资源预算明确失败，未使用旧初始化导入的16文件／128KiB限制。目录本身有10000日志／100000目录项预算；未把这些有界检查当成任意规模历史已验收。

## Native反馈与动效

保留固定右栏、单个历史勾选和底部启动位置。选择读取中不能开始；读取失败可在历史区域重读，取消勾选后恢复只整理仓库。所选历史变化的明确拒绝只显示一处重新选择入口；真实未知启动响应仍保留原意图，不能混成已确认的历史拒绝。

运行时历史选择只读，阶段文字明确「项目与历史会话」。失败的历史范围明确报告未完成，不用完成书掩盖；启动前历史选择失败也停止舞台循环。Native复用原C阶段几何、稳定Key及减少动态效果规则，视觉时间不触发读取、模型、保存或完成。历史异步读取有独立且跨重开单调递增的序号，关闭／切项目／重配库后旧回执不填充新选择。
