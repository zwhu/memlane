## 已选方向与本轮变化

保留已选定的宽幅首页、均衡三栏、浅蓝连续侧栏、白色内容区、单色图标以及会话式 Markdown 阅读。用户本轮授权的是范围删减；当前稿不增加新视觉分岔，不将历史候选整体提升为已认可功能。

当前界面只有总览、知识与原始记录、搜索、出处、官方图谱、必要设置。通用知识复用只读知识页。所有内容直接来自 Cognee，桌面只保存必要配置和阅读状态。

## 页面与实际职责

| 页面 | 界面职责 | 数据和操作所有者 |
| --- | --- | --- |
| 总览 | 项目入口、近期知识、真实状态 | Cognee 内容与本机连接结果 |
| 知识 | 分页列表、Markdown、复制、来源 | 官方文档与来源接口 |
| 原始记录 | 会话和文档阅读、工具展开、已载入范围 | 官方 sessions、QA、trace 与原始文档 |
| 搜索 | 项目分组、查询、真实结果定位 | 官方搜索与召回接口 |
| 实体图 | 承载官方画布与现成面板 | 官方图数据与组件 |
| 代码图谱 | 当前项目索引开关、手动更新、来源 | 官方索引与图组件 |
| 设置 | 官方服务位置、Codex 当前状态和必要项目关联 | 当前本机配置与官方连接认证 |

首次开启代码图谱调用官方索引，后续明确点击“更新代码图谱”。关闭后不发起新扫描；已有任务依官方能力处理，不显示虚假取消结果。

开发期后台由开发启动器管理。关窗不停止后台，重启电脑后手动启动；设置只提供可理解的状态和入口说明，不再增加后台管理平台。

## 必须保留的交互

1. 列表、正文、来源指向同一官方对象，使用服务、dataset、类型和官方 ID 保持身份。
2. 项目切换取消旧视图请求，迟到结果不得覆盖新项目；同一项目内保留选中、滚动和工具展开状态。
3. 首次加载、真实空结果、无匹配与读取失败分开。已有内容刷新时不闪空、不把计数归零。
4. 内容被官方替换或失效后明确说明，不把缓存正文继续标为当前。
5. 来源通过实际关联跳转，返回时恢复阅读上下文。没有关联时说明缺失，不制造逐轮出处。
6. 长正文在阅读栏内滚动，代码独立横滚；普通按钮与信息展开留在栏内。
7. 列表选择、工具展开、复制、返回可用键盘操作，焦点顺序跟随当前页面内容。
8. 模型、连接和处理状态只展示真实已知信息；无进度百分比时显示处理中，不补造进度。

## 布局与承载

默认和最小窗口均为 1200×820，允许放大。首版不设计或实现窄窗口及响应式布局，不新增相应尺寸或焦点适配矩阵。首页为侧栏加宽幅内容，其余阅读页面为侧栏、列表和正文。会话阅读参数见[阅读交接](conversation-reading-handoff-20261112.md)，首页与设置见[非项目页面交接](non-project-handoff-20261112.md)。

MyGo 承担原生窗口、阅读与基本设置；图谱在 WebView 内承载官方组件。图组件只接收所需数据和导航事件，不获得后端凭据或任意文件、命令能力。

## 已删除的交付要求

当前设计不再包含手动内容增删改、版本与 diff、旧版恢复、审核建议、复杂整理、计划、权限管理、多模型配置、动态启用账本、备份恢复界面、索引维护中心、更新及正式分发设置。相关旧场景不再要求实现或重跑。

不为保持旧卡片、按钮或菜单而补建自有业务后台、正文副本、重复索引、任务表或使用账本。官方接口缺少非核心展示字段时，删除对应展示承诺。

本轮只清理设计资产和文档，不恢复生产开发。后续获得实施指令后，按确定接口直接开发，必要检查针对实际变更，不再新增路线验证或恢复旧全量矩阵。

用户确认本版保留通用知识入口，正文明确显示官方暂不支持；不把空映射或项目摘要称为个人偏好／通用经验。后续再采用独立官方通用知识dataset，供所有已连接Agent读取，本轮不提前实施或引入权限管理。
