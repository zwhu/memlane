## 正式契约与所有权

1. 审核请求增加可选的用户编辑内容，限标题、通用表述、适用条件；禁止借此修改目标范围或原引用。模型原候选和结果保留，用户确认内容写入独立通用经验，并随保存回执保留。现有回执JSON承载新增字段，没有数据库schema迁移。
2. 原子审核仍核对原候选摘要与来源当前版本。空字段、超长内容、将编辑字段放入拒绝或其他动作、来源过期均被拒绝；重放必须与原确认内容一致，不能换正文或适用条件，也不能把已编辑回执改为原候选确认。已经保存的同回执可在来源变化后继续读取，不重复创建知识。
3. L04启动只提交预期的处理配置修订和选择代次。daemon在创建任务事务内冻结已启用、已验证的配置及真实依赖回执，与输入材料一起封入任务快照；配置切换不把运行任务改派给另一个执行者。重复启动先返回原任务，再决定是否需要解析新运行依赖。
4. 本批实际执行为 pi／DeepSeek 的受管独立结构化推理，复用已验证 pi 运行器；生成前、返回后再核对连接代次、验证状态和依赖散列。任务使用既有并发槽位、进程租约、PID注册、取消和进程回收；结果经过完整Schema与精确引用核验，生成完成只产生待确认候选。
5. 新分派只覆盖本批 L04 单来源通用经验；旧任务和未带处理授权的旧整理／计划路径保留对应 traex 契约。独立Provider、Codex处理桥、Magpie及其余任务分派不得由本结果关闭。

## Native还原

- 从项目知识进入“通用知识”上下文，右栏显示冻结来源版本和候选；宽窗口并排，窄窗口堆叠／局部滚动。标题、通用表述和适用条件有可见字段标签，确认动作固定底部。
- 入口明确模型额度消耗。读取配置、提交、实际生成、未生成候选、等待确认、已保存、拒绝、取消请求和已回收分别显示；不依赖计时推进成功。原候选与生成说明可按需展开，不把模型返回的 `purpose/global_experience` 等内部说明默认放入日常正文。
- 运行中可明确取消生成；正常返回知识保留任务。切页和回看同任务不重新运行模型；草稿按原候选身份保留。重新生成明确再次消耗额度，并创建新的真实操作身份。
- 来源变化后保留预览与用户草稿，冻结输入并禁用确认；后台已经将候选标为过期时仍保留该禁用动作。明确重新生成取新的来源版本。整库或library重新配置时退休旧预览与旧回执。
- 提交确认后冻结请求。回执读取失败保留同一请求重试；来源变化不会阻止已提交确认的回执恢复。保存和Rust索引分别显示；失败、拒绝、过期和取消不改变原项目知识或自动保存通用经验。
