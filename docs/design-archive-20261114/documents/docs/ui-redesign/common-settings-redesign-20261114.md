## 连续行为

- 通用知识默认阅读，单库不显示库选择；新增或编辑的草稿可返回阅读后继续。编辑现有知识保留原分类、来源和提交前正文摘要核对。
- 提交后锁定原草稿及回执。正文保存与处理终态分别核对；未知写入只核对原操作，不提供第二次提交。已知文档ID的保存核对不受第一页30条限制。
- 删除先确认具体知识；未知删除结果只GET核对。官方明确仍保留后，才允许重新明确确认删除。
- 左侧项目行右侧“⋯ → 项目设置”进入对应项目设置；返回恢复原阅读pane。侧栏设置始终进入全局设置。访问权限包含读取／写入／删除、不包含分享；继承、覆盖和后端版本核对原契约保留。
- “改为继承默认”只修改草稿，“保存此 Agent 的设置”才写入；“撤销未保存修改”读取当前已保存覆盖。页面显示已保存值，不把未保存草稿说成已生效。
- 待发材料按真实绑定会话分组，显示会话标识摘要；仅用户点击核对后读取材料状态。补交与丢弃保留原显式操作及未知结果保护。
- 首页进入时、重新聚焦时和前台每30秒自动读取；失焦／隐藏及搜索弹框中不新增周期读取，不清空有效内容／分页／滚动。正常态移除刷新入口，失败保留重试。底部“Cognee 保存与处理”及日期装饰行删除，左侧连接状态保留。
