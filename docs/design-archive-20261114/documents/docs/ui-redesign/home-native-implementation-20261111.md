## 实施结果

- 新首页复用MyGo与原生热力图、任务按钮和底部计划；新增真实项目知识卡片，数量读取同一项目列表所有者；未知／失败不冒充0。空项目仍能新增，整理不成为前置条件。
- `home_activity` IPC读取不可变版本事实和已提交的日常Agent使用事件。检索返回、成功读取、明确采用分别呈现；连接验证、App浏览不会混入日常Agent动态。原有90天使用事件保留边界不扩展为删除知识／审核历史。
- 动态稳定ID、原时间、记录版本和标题不由当前知识覆盖。确认跨项目移动后，原事件仍属于记录时的项目；“查看当前知识”使用最新所属项目。知识／原始记录保持类型。
- 首页只显示4条动态；完整列表每页8条，支持项目／类型、前后翻页、总量和读失败保留。完整列表不被首页自动刷新重置。
- 动态详情通过正式History/Get读取记录时版本正文及当前版本，长文使用已有完整分段阅读组件；“查看当前知识”不会被当成Agent采用。
- `home_review`统一读取合并建议、材料整理审核建议和通用经验建议，读取事务复核来源版本与目标范围，过期、取消或已决定项不计为可审核队列。读取本身不应用建议。
- 首页只显示3项待确认；完整队列按项目／建议类型筛选、每页8项，列表选择直接复用现有严格审核拥有者的右栏差异、确认／拒绝、过期校验、持久化与回执；新增 `selectOrganizationAt(task,item)` 在异步恢复完成后定位具体建议，不覆盖原草稿或跳过审核规则。
- 日期选择继续查看当日知识；“查看全部知识”进入全局搜索的空查询列表承载，并保留日期。首页与具体详情使用独立滚动状态；提供返回动态／待确认的具体上下文入口，普通侧栏总览仍回普通首页。

## 定向证据

真实SQLite定向测试覆盖：日常read/return/adopt与save/edit的独立事实；重放不重复；排除验证事件；稳定游标分页和过滤绑定；确认移动后历史归属与当前入口分开；统一待确认、过期排除、拒绝后移出队列、只读不改变版本数。UI定向测试覆盖：按稳定ID进入当前所属项目、原始记录类型保持、日期进入搜索与返回上下文。
