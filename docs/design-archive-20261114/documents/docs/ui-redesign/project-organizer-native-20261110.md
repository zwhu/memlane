## 已实现的操作边界

- `ConfigureLibrary`接入真实 `ProjectTaskClient.Start`。只有已加载、可用且支持本项目整理的 Codex 绑定允许开始；未接控制器、不支持的 Agent 和历史读取继续明确不可用。
- 启动中的操作保留相同操作ID。关闭、切页或重开面板不重复启动；没有明确任务ID时读取当前项目活动C任务。新尝试通过显式「重新整理」生成新的意图，完成后的后续补充仍从项目菜单进入。
- 「查看知识」只离开承载；项目菜单「查看整理进度」恢复同一任务和尝试。停止按钮发送真实取消请求；收到服务回执才采用取消中／终态。服务负责中断与回收进程组，绘制不发送取消或推进阶段。
- 运行与结果保留任务的固定项目、绑定Agent、模型与历史选择。关闭不会恢复成可编辑范围；新整理前清除历史选择。库重新配置与旧异步回执隔离，项目总览读取也固定原ctx、library与client。
- 运行时顶部只有一处「查看知识」，底部负责停止／重试；完成后底部提供「查看项目知识」。真实保存与索引计数来自任务回执；无新增、部分保存或索引失败不冒充新增全部成功。
- 启动未确认和停止未确认不被定时读取清掉。没有读到对应真实任务／取消状态时继续保留反馈；用户明确「重新读取」后才能重试，保持原意图ID。读取到真实任务或取消状态可以解除对应的不确定反馈。

## Native 舞台与参数

独立组件位于 `internal/desktop/project_motion.go`。`projectStageMotion`拥有当前显示姿态，任务阶段由服务快照输入。24个方块使用固定散落序号、三面明暗、旋转与Z深度；归整为6×4、间距22，正面14、厚度5，场景按560×280逻辑坐标换算。仓库／知识卡片、光晕、地面、知识书与完成标记共用同一场景绘制。

| 输入状态 | 当前表现 |
| --- | --- |
| 待开始 | 固定散落，6秒漂浮；空知识右栏预览复用几何 |
| 空态按钮悬停／键盘聚焦 | 700ms、逐块20ms归整预览；不创建任务 |
| 排队／启动 | 850ms、逐块25ms归整；只等待真实任务回执 |
| 整理 | 1.7秒起伏循环，逐块90ms相位 |
| 保存 | 800ms、逐块30ms汇入知识卡片并淡出 |
| 索引 | 卡片1.6秒扫光；知识保存和索引分别报告 |
| 完成 | 书体850ms、书页900ms展开，550ms后用350ms出现完成标记 |
| 失败／取消中／停止／中断 | 归整静态方块，透明度0.35，无完成书／勾、漂浮或扫光 |

方块计算750透视的深度坐标，书页计算600透视；整个舞台通过 MyGo `Perspective`、`RotateX/Y` 接入指针视差，最大3.5°／5°，300ms缓动回位。稳定场景Key为 `project-knowledge-stage` 和 `project-empty-preview-stage`，任务／尝试变化与重入独立处理。快速阶段变化从当前显示位置插值；同阶段更新不重新播入场；重开恢复当前阶段。

常规舞台280，空态预览300；小于1100宽或740高时分别150／210，正文内边距从24降为12、间距从16降为8。普通和980×620窗口的结果计数与固定操作均可见。系统或App减少动态效果均使用阶段静态目标，停止自绘帧请求和视差。舞台离开、被裁切或窗口隐藏后不保留全局视觉计时器；业务任务仍由daemon运行。

当前常规读取周期为2秒，快速保存／索引阶段可能在两次读取间结束；不会为了播放完整动画延迟业务完成。纯采样覆盖全部阶段，不代替每个阶段的实际窗口证据。
