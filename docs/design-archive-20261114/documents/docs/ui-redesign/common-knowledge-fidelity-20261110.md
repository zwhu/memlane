# 通用知识名称、分类与原文复制：Native 实施

2026-11-10。本批依据已确认命名稿 `d2e3923de31ecd4bf7288c2527a9b98578a1ef17` 和[专项交接](common-knowledge-naming.md)，叠加基础 `780745fc55d71edb22e46d9c3e4f208d5ecb602f` 的 L01–L05。设计认可范围和全量开发授权继续分别记录。实施前已实际打开首页／三栏设计图、通用知识普通／窄窗口和复制预览固定图。

## 实施内容

- 侧栏、页面标题、范围、来源、复制／提炼、Agent 范围与计划提示显示“通用知识／个人偏好／通用经验”；全部记忆一级入口保留。显示名按正式 scope kind 映射，内部 kind、ID、已有存储名称、权限与来源版本不迁移；历史来源只在展示时转换。
- 知识内直接提供两类按钮，初次同时浏览，再点选中分类可清除。分类请求读取正式 scope ID，不按记录标题、标签或示例类别推断；范围尚未取得时读取失败，空 datasets 不被解释为全项目。分类数量和完整通用知识／原始记录数量分别读取。
- 切换分类保留匹配详情，否则选取同类首条；零匹配清空详情。原始记录页签不套用知识分类；回到知识恢复分类。查询代次阻止晚回执覆盖新分类，刷新不改变用户正在编辑的草稿。显示名冲突使用 scope ID 消歧，旧草稿名称只解析唯一既有通用 scope。
- 项目知识“原文复制到通用知识”进入通用知识上下文。右栏显示原来源版本、只读完整正文、可编辑标题和适用条件；宽窗口并排来源／副本，窄窗口堆叠并局部滚动，确认按钮固定底部，取消返回原项目与阅读位置。复制不运行模型。
- 保存新增独立 experience 知识及适用条件，保留原项目知识、完整版本和来源快照。首次请求冻结标题／条件／操作 ID；同请求重试不会重复保存，改变条件的重放会被拒绝。旧客户端不含新增字段时继续沿原请求契约重放，避免名称修订破坏旧回执。
- 预览独立读取来源当前版本。来源变化或读取失败时阻止新确认，重新预览取正式当前版本；已提交请求仍能核对原保存回执。来源关联不授予原项目读取权限，项目明确约定继续优先。
