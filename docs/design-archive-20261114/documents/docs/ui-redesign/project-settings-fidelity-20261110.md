# 左侧项目菜单、整个项目设置与授权验收

2026-11-10。实施依据为[项目入口与范围](project-settings-placement.md)，固定原型`5d99324`；A/B/C原有认可版本保留。本批落实左侧项目省略号、右栏项目设置和单项目授权，不将项目权限描述为电脑级Agent连接已完成。

## 已实施

左侧每个项目提供独立省略号，当前、悬停和键盘聚焦时显示。展开其他项目菜单保留当前正文、查询和阅读位置；选择「项目设置」才进入菜单所属项目。Escape关闭菜单并把焦点交回对应省略号。

右栏设置固定到整个仓库项目，显示实际项目名称、路径、Agent连接类型、项目访问状态和默认使用范围。知识与原始记录共用授权，Git worktree仍采用已有正式仓库身份。关闭设置保留原阅读／编辑；切换项目保留未保存草稿；设置打开期间另选知识不会恢复旧条目的编辑器。新增记忆会进入新编辑器。

权限保存通过包内daemon的`connection_project_access`，由Agent访问写锁和SQLite事务负责。只修改目标项目的scope，校验连接代次，保留其他项目、全局范围、固定／待定项目与trusted workspace。真正变更才换代次；重复授权不换代次。旧代次立即失效，断开／退休连接不能通过项目授权重新启用，固定或待定项目的撤销须先解除绑定。

保存不宣称重载或验证已经完成。已有installation的连接复用自有配置安装器更新；重载与再验证仍是后续独立步骤。并发冲突不显示本次保存成功；重新读取后需要按最新代次重新编辑。提交中的操作有独立拥有者，切页和迟到回执不覆盖新项目；未知状态与停服读取失败不显示为空项目或零连接。
