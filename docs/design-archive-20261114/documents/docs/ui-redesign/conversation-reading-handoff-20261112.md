# 精简版知识与原始记录阅读

2026-11-12。用户此前已选择会话式 Markdown 阅读和均衡三栏方向；本轮按“已砍掉的东西都删除”清理导航、按钮和交付要求。当前稿为[精简版规格](../client-simplification-spec-20261112.md)中的只读阅读，不再承载手动编辑和内容版本系统。

当前入口为[知识](../../build/p3-prototype/prototypes/client-simplification-20261112/index.html?scene=knowledge)、[原始记录](../../build/p3-prototype/prototypes/client-simplification-20261112/index.html?scene=records)和[截图目录](../../../../images/ui-redesign/client-simplification-20261112)。原型示例是合成材料，不是实际聊天或生产结果。

## 信息结构

保留项目“知识／原始记录”页签，不新增顶层会话入口。知识显示官方生成的可复用内容，原始记录显示官方实际保存的会话或文档；二者不因为处理状态而互换类别。

中栏按官方对象列出内容，右栏显示选中正文。原始会话按问答阅读，工具记录默认折叠；非会话材料保持独立文档阅读。来源只通过官方关联跳转，返回时恢复原知识和阅读位置。

## 数据映射

以下只在内存归一化，不新增正文数据库。

| 视图字段 | 上游依据 | 缺失处理 |
| --- | --- | --- |
| 对象身份 | 官方服务、dataset、对象类型及 ID | 不按相似标题拼接对象 |
| 会话标题 | 官方标题，否则已载入非空 question 首句 | 显示“未命名会话”，不另调模型取名 |
| 摘要 | 已有正文短摘 | 可空，不生成推测摘要 |
| 日期与活动 | 官方消息时间或会话时间 | 显示“时间未知”，不将采集时间冒称发言时间 |
| 用户消息 | QAEntry.question | 空值不补造用户发言 |
| Agent 消息 | QAEntry.answer | 空值不补造回复或输入动效 |
| 工具记录 | 官方 trace 的名称、参数、结果、状态与错误 | 缺失显示未提供，不从正文猜测 |
| 工具与消息关系 | 官方明确关联 | 无关联则独立列为本会话工具记录 |
| 顺序 | 官方顺序或事件时间 | 保留上游顺序，不强造问答与工具交织 |
| 已载入数量 | 实际返回内容 | 不当作完整会话总数 |
| 知识出处 | 官方来源身份与关联 | 说明缺失，不以知识正文冒充原文 |
| 处理状态 | 官方真实字段 | 未提供则省略，不推断完成 |

只有尾部或片段数据时明确“已载入”范围，不承诺完整聊天归档。缺少字段不通过复制全文或读取 Agent 全部历史来补造。

## 阅读交互

1. 选择内容后按官方稳定身份读取，切换项目取消旧视图请求，迟到结果不覆盖新项目。
2. 项目搜索进入官方查询，搜索与分页分开；局部过滤不能替代产品搜索。无匹配不显示成空库。
3. 工具默认折叠，展开后呈现实际参数、结果或错误。无工具不显示空组；长结果留在右栏内阅读。
4. 记录信息在右栏展开，显示实际来源、身份和时间；缺少字段时省略对应行。
5. 查看知识出处后提供“返回知识”。有精确片段关联则定位；没有时打开实际关联材料并说明范围。
6. 提供正文复制、单条或代码复制，底栏若复制部分内容应写“复制已载入内容”，不称完整会话。
7. 首次加载显示局部反馈；刷新保留旧内容、焦点、选择、滚动及展开状态。失败保留上次有效内容并提供重试。
8. 列表与正文各自保留阅读位置。后台新增不强制滚动到底；只保存必要客户端偏好和临时阅读锚点。
9. 官方明确失效或替换的内容撤下，暂时读取失败与内容失效分开，不把本地旧正文继续标为当前。
10. 按钮支持键盘操作，Tab 顺序跟随列表工具、条目、阅读工具和正文；展开不打断焦点。

## 实施边界

正文使用 MyGo 的 Markdown 能力，图谱另由官方 Web 组件承载。原型 HTML/CSS 表达外观与交互，实际页面仍由真实官方数据驱动。

当前页不保留新增、编辑、删除、内容历史、差异、恢复、审核、提升为通用知识或权限操作。只读不禁止官方插件保存材料或 Cognee 自动生成知识。
