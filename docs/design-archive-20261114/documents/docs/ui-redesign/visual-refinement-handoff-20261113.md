## 关键操作契约

| 连续路径 | 必须保留的状态及反馈 |
| --- | --- |
| 总览 → 项目 → 知识 → 出处 → 返回 | 按服务、dataset、对象类型和 ID 建返回栈；逐层恢复原选中与阅读锚点，不用单个 return 字段覆盖 |
| 搜索 → 筛选 → 结果 → 详情 → 返回 | 恢复查询、项目、内容类型、原结果、滚动与选中；官方搜索负责检索，原型本地筛选不能替代它 |
| 原始记录阅读 | QA 与角色清楚，工具默认折叠；缺少精确关联的工具独立列出；明确已载入范围，不称完整聊天档案 |
| 复制 | 知识复制官方正文，代码复制当前完整代码块，原始记录复制已载入范围；失败给可执行反馈 |
| 刷新／切页 | 后台刷新保留有效内容和展开，迟到响应核对对象／请求代次；切换条目不重置列表。刷新后恢复阅读状态，不持久复制正文 |
| 通用知识管理 | 分类、正文、适用条件、原始来源；编辑前核对正文版本，分类和来源保持；提交后锁字段、防重复提交，核对原保存与处理终态分别表达 |
| 删除通用知识 | 栏内说明后果，确认此条／保留；官方确认后撤下旧正文与复制，不把请求发送视为删除完成 |
| 默认／覆盖 | 草稿与已保存规则分开；继承为缺省/null，不是 false；修改默认只更新继承字段。逐安装实例覆盖／恢复，显示实际有效权限和同步状态 |
| Agent 接入 | 准备 → 查看变更 → 明确启用 → 等待新会话真实回执；旧消费者／配置冲突阻止启用，不假造新会话成功，不迁移既有会话 |
| 新建／关联 | 同一稳定身份去重，同名不同路径不合并；关联保留已有覆盖及 ACL。显示待核对／冲突，不能自动重发未知写入 |
| 待发材料 | 403 后暂停，恢复权限不自动补交；明确补交／丢弃单项。丢弃不删除来源会话；在途结果未知保留原操作 |
| 图谱 | 项目图谱页内区分实体与代码，分别选官方数据组；官方画布负责节点／缩放／详情。代码首次显式开启，后续手动更新；关闭不宣称取消在途任务 |

原型用 sessionStorage 演示当前标签页刷新恢复，仅存人工视图状态。Native 复用现有阅读状态及返回栈，不因此增加第二套正文库。原型的内容修改／设置只在内存演示，刷新重置；生产持久化语义仍按上表及现有服务契约。

## 状态和真实字段依赖

| 状态／区域 | 数据依据与展示 |
| --- | --- |
| 首次读取 | 请求状态；局部反馈，不用空列表代表仍在加载 |
| 后台刷新 | 保留上次有效内容和数量，短提示；不跳回顶部 |
| 真空／无匹配 | 成功返回空内容／筛选结果为零分别表达；入口指向连接设置／清除筛选 |
| 暂时失败 | 明示内容未刷新，保留旧正文、目录、计数；只重读，诊断收进展开或复制 |
| 失效／撤权／替换 | 官方明确无效后撤下正文及复制，返回有效列表；不以旧缓存冒充当前 |
| 处理中／完成 | 官方任务实际状态与实际结果；不虚构百分比或新增数量。提供原始记录／知识下一步 |
| 标题与片段 | 官方标题或现有可读首句规则，不调用模型生成标题；原型长技术标题保留用于承压 |
| QA／trace | question、answer、真实工具名／参数／结果／关联；无问答明确说明，缺失时间显示未知 |
| 通用知识 | CommonDraft 与 CommonWriteReceipt，官方 DataID／PipelineRunID、正文摘要核对；不将保存成功算处理成功 |
| 策略 | project_id、安装实例 ID、默认模板修订、显式覆盖、期望／已核对修订；未知与部分成功不得标已生效 |
| 服务／图谱 | 实际连接和健康结果、项目代码开关、官方图数据及真实路径／行号；不承诺本地编辑器跳转 |

Native 对应位置：`internal/simpledesktop/app.go`、`overview_ui.go`、`reading_presentation.go`、`reading_loading.go`、`project_access_ui.go`、`project_connection_ui.go`、`project_buffer_ui.go`、`common_knowledge_ui.go`；图谱为 `web/official-graph`。沿用这些模块现有真实接口，不引入业务写接口模拟层。
