# 编辑页术语集中修订

依据：当前H02候选图、内容分层契约、015长草稿实窗偏差记录。全局“新增记忆”仍表示入口，手动编辑和保存产生的是知识；原始记录不因此改类型。

## 编码前用例

| 场景 | 预期 | 验证边界 |
| --- | --- | --- |
| 已有知识进入编辑 | 右栏标题“编辑知识” | 源码与现有组件检查；新包Native待集中验证 |
| 新增或编辑手动知识 | 主按钮“保存知识”，稳定Key为memory-save | 不改变点击回调、禁用、版本和草稿规则 |
| 服务未连接 | 保存按钮禁用，导航保留草稿 | 复用TestShellWithoutEngine，不新增镜像实现的文字测试 |
| 整体导航及内容类型 | 全局“新增记忆”保留，原始记录阅读不改变 | 不做全局字符串替换 |

本轮仅源码集中修订与必要定向检查，不为两处文字单独完整打包，不触发已经停止的后台更新或图谱验收。当前015实际窗口与截图继续代表旧文案，不能作为修改后的视觉通过证据。

## 本轮源码结果

编辑页标题已改“编辑知识”，新增和编辑的主按钮改“保存知识”，新增稳定Key为memory-save；回调、禁用条件和草稿/版本逻辑未改。原全局“新增记忆”和字段Key保留。现有TestShellWithoutEngine与历史焦点最终定向检查通过，desktop vet通过，四个改动Go文件gofmt无输出。

旧验收脚本中按“保存”文字定位的手动编辑步骤尚未全部迁移，不能直接作为当前候选源码的通过证据；后续统一Harness应使用稳定memory-save Key，不批量改写历史脚本和历史报告。源码修改未打入015。
