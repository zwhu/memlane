# Native 设计还原第一轮

2026-11-09。用户在核对实际窗口与认可稿的差距后要求开始还原度开发。本轮按 A revision 13、B revision 5 和已确认的 Agent 设置入口实施；不将页面还原当成批量安装、模型后端或正式任务分派完成。

## 本轮改动

| 部分 | 本轮落实 |
| --- | --- |
| 初始化承载 | 品牌图形与文案、196 DIP 浅蓝侧栏、154 DIP 三步栏、标题与步骤位置；删除侧栏工程说明 |
| 记忆处理 | 初始化与设置继续复用同页；连续分段页签、状态栏右侧启用、两列自适应单选卡片与单色图标；只显示当前模型与额度提示，移除工程边界和技术验证表格；失败原因仍保留 |
| 设置导航 | 环境与组件／Agent 连接／记忆处理放入浅蓝侧栏，删除额外中间导航列；保留返回日常首页的路径与已有草稿 |
| Agent 连接承载 | 真实发现与连接状态改用两列卡片；设置页保留各已有连接及非 pi 的新增连接入口；首启 Agent 页定期读取实际验证回执 |
| 首页 | 删除大块旧引导；累计原始记录、有效知识和使用天数三个位置；全年知识事件、最近知识与待确认并列；整理计划摘要固定在底部 |
| 日期与类型 | 点击日期只过滤首页知识，再点解除；日期跨详情导航保留；异范围读取失败不沿用旧列表、不冒充空结果；知识详情和列表种类跟随实际条目 |
| 整理入口 | 方块图标和实际运行状态；活跃任务由 daemon 单独查询并优先执行中任务，点击恢复原任务，不从分页历史猜运行状态 |

`ActivitySummary.raw_total` 按原始记录身份去重，不累计版本，归档后仍保留接收事实；`knowledge_total` 排除非 active 和当前修订失效的派生知识。两项与日期筛选独立。没有受信首次使用日期时显示未知，不根据最早知识或文件时间补造日期。本轮不新增 schema，不改变已保存知识、版本和采集授权。
