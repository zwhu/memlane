## 已实现边界

- daemon为本次任务提供独立 `memlane_project_knowledge` 只读工具。项目、任务、尝试和所有者由服务固定，模型只传分页cursor，不能指定其他项目、原始记录、历史版本或Agent。
- 每页核对真实当前任务访问状态、仓库身份、绑定修订／代次、租约和运行阶段；只读取当前有效知识，排除原始记录及失效派生条目。保存有效但尚未索引的正文仍可读取。
- 单页最多20项，并按实际JSON字节限制分页；整次读取有32MiB预算。无截断后声称全部完成；读取失败、版本变化、未知cursor、数量不完整或超限均终止任务，不释放新增结果。
- 已读页可以重读，但重新核对服务权限和当前页内容；撤权或版本变化不能绕过缓存继续披露。范围冻结，知识按每次实际读取版本记录；不将整个模型执行期间描述为禁止用户编辑。
- 已有知识只用于避免语义重复、保留项目约定与识别待确认冲突；所有新增候选仍必须通过 `memlane_project_source` 取得真实仓库出处。上下文读取不保存、不合并、不覆盖、不删除或移动已有知识。
- 补充整理仍使用绑定Codex的真实当前模型与正常仓库工具，不切换记忆处理Provider／Agent／Magpie，不读取用户历史作夹具。

## 回执与证据含义

模型执行回执增加可选 `knowledge_context`，保存页数、项目知识数、字节数、读取完整性、实际已写入本次工具响应的页数，以及按顺序累计的SHA256摘要。不把“服务读取成功”直接当成“响应已发送”；发送失败不会满足仓库引用与最终候选释放条件。字段保持有界，原schema19记录没有此字段时不补造旧能力。

摘要覆盖每页返回的具体知识ID、版本、标题与正文。回执不会持久化另一个副本的知识正文或配置／凭据。成功模型terminal、上下文回执、保存、出处与索引分别证明；完整读取和发送也不单独证明模型语义质量。
