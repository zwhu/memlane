# 记忆处理：配置修订与执行所有者

2026-11-09。A1工程契约，依据已认可的 [页面复用](ui-redesign/reusable-setup.md)。pi实际桥及同包验证已通过；本页定义接入统一配置前的持久边界，不能把账本、协议夹具或保存候选称为三种后端已接通。

## 配置与验证

- UI只拥有当前查看方式和各方式草稿。保存请求通过daemon单写SQLite，创建不可变配置修订；每种方式保留一个最新已保存候选，另保留完整历史。一个独立当前选择指向有效修订，不跟随已保存候选变化。
- Provider独立凭据使用不可变私有凭据版本引用，不将Key存进配置SQL、响应或报告，不取pi认证代填。多个模型可以复用同一供应商凭据版本；保存新凭据版本不能覆盖运行中或当前修订引用的旧版本。
- pi/Codex配置绑定已连接身份与代次，模型选择、实际版本和认证/config指纹由执行者检查；无项目身份和电脑级安装证据仍分开。Magpie仅允许本机loopback，公共目录与模型支持须实际核对，不读取其私有供应商Key。
- 验证任务由真实运行者完成，绑定修订摘要、依赖指纹及尝试号。失败、取消或新尝试保留旧回执；迟到成功不能覆盖取消或更新后的尝试。SQL只验证回执所有权和状态，不自行证明Schema、取消、认证或采集隔离成功。
- 启用是独立显式动作：要求当前候选、最新验证成功、实时依赖指纹仍匹配，以及当前选择代次CAS。启用原子改变选择，不修改旧修订或其他方式，不自动故障切换。验证失效时当前选择保留且准确显示不能执行，不能静默改成其他后端。

## 任务冻结与真实执行

后续整项Cognee提炼、手动整理、计划执行在启动时冻结同一修订、选择代次及验证指纹，不逐个HTTP请求重新读取当前选择。运行中切换只影响后续任务；不取消、重启或重写已经启动的任务。保存候选不进入任何执行路径。

冻结必须与正式任务/attempt创建处于同一持久事务；调用模型和网络在事务之外。现有原文/知识/来源、审核、租约、取消、有限恢复及stop epoch继续由daemon掌握。统一执行槽位包含Cognee和P3整理；App只发动作和显示快照，不另启一个不受租约约束的自动重试循环。

当前Cognee配置与桥仍由App的official.Controller管理，正式P3整理与计划仍调用traex。接入前必须迁移执行所有权并取得整项多请求冻结证据，不能只改Cognee环境变量或底部模型名称。新账本未接该执行路径时明确标为基础结构。
