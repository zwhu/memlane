## 内容与连接

知识和原始记录是不同内容类型。仅呈现官方实际保存的内容及来源，不把材料接收、开始处理或任务完成直接算作新增知识。列表、正文和搜索来自同一官方存储，刷新保留有效阅读位置。

Agent 采集与召回复用固定官方集成；各接入指向同一服务，受管 Agent 使用独立官方子主体，管理 owner 仅用于管理。访问级别为不可访问、只读、可写并维护；最后一档包含官方 read/write/delete，不授予 share。无 owner、共享角色或离线 CLI 回退。

新仓库由管理侧自动登记并建立独立官方数据组，首次写前绑定正确归属。访问、自动采集、自动处理逐字段继承默认规则，项目覆盖优先；关闭采集时先推进无正文水位，不回扫禁用期。403 待发材料停止重试，权限恢复后只由用户明确补交或丢弃；未知结果先核对原操作。关闭自动处理只停止后续触发，不表示取消已运行任务。

通用知识独立存储，Agent 只有可读权限时才在原 coding 注入入口内合并使用，项目明确约定优先。新项目代码图默认关闭；项目、通用和代码数据组保持区分。既有会话和合法材料不自动迁移、补采或重放。

Agent连接与知识处理模型分别配置。保留Codex订阅推理，新增Cognee官方Provider直连；允许保存多个配置，只有一个当前使用。保存、消耗额度的验证和“下次启动使用”分开，正常重启确认成功后才应用；失败按原配置最多恢复一次，清理未知则停止。embedding沿用原配置，处理会话隔离日常采集与工具，避免重复记录自身输出。
