## 用例与执行顺序

1. **发现和安装兼容**：Codex App-only/CLI-only/两者并存；各宿主默认/自定义目录/环境变量/歧义；未安装/非可执行/升级路径。验证现有prepare/activate/review，保存登录与其他插件，禁止错误配置自动换目标。
2. **插件协议与权限回归**：官方固定输入、manifest/安装摘要、真实回调结构；初次接入前不补采历史，恢复/分支不串会话；403明确拒绝与unknown区分，未知不重投；采集与处理会话隔离、不形成循环。
3. **当前已连接三家真实连续流程**：先核对原有新鲜来源、官方已保存QA/trace、处理状态与来源正文；缺口再用明确的小型正常任务验证，不为统计补造知识。不更改原项目约定；未知写入先核对。
4. **未连接宿主**：先完成无账号的协议/安装夹具；真实日常接入逐项展示具体配置预览，遇登录/信任或缺少安装前置保留阻塞项，不假报通过。
5. **记忆处理和采用**：当前Codex桥与已配置Provider分层；事实、现状替换、来源/日期、语言、项目权限、跨Agent采用分别验。模型和官方后台容量空闲才执行受控真实调用。
6. **失败与连续使用**：离线、重载、超时、取消、重复提交、配置变更、撤权、长会话增量、重复采集、未知跨重启；Native显示与后台事实一致。重启必须核对共享所有权及在途任务，不为测试强制重启日常服务。
