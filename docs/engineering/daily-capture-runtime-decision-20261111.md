## 为什么不能只更新 GUI

例：用户确认 item-fe 项目，同时把已保存的四条原始记录关联进去，然后继续一轮对话。

既有用户归属接口可保存前四条，但其语义是独立、逐条明确用户确认。后续新对话若自动调用该接口并声明 UserConfirmed，会把一次旧授权冒充新的逐条手动动作。本轮不会这样实现，也不以 App 自动建立项目、调用模型 memory_save 或让用户手动要求保存替代自动采集。

后续自动归属需要后台识别一项持久、可撤销的“此已授权 Agent 的此仓库原始记录归入此项目”规则。此规则只准保存原始记录，不增加项目知识读取、跨项目检索、通用知识权限或模型整理权限。

6. 整理：继续使用现有 Native 材料选择、范围/Token 提示、pi 任务、用户确认知识及来源阅读，不重建整理服务。
