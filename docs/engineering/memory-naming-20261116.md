# 记忆命名统一

用户明确选择“知识→记忆、通用知识→通用记忆”，并指定“沉淀依据→记忆点”，随后授权实施。

本轮仅调整Native系统文案及可访问名称：首页统计与热力图、侧栏、项目页签、卡片与详情、来源返回、未读提示、统一搜索、通用内容管理、设置/处理模型及权限说明。现有正文、官方数据、route/Item.Kind、搜索过滤值、已读记录键保持原样；Tabs与搜索Segmented单独映射显示名称，避免改名导致跳错页或过滤失效。后台动态名称整理/搜索/召回同步记忆称谓，队列接受新旧活动标题。

实窗核对：通用记忆、记忆Tab、搜索记忆与原始记录、搜索分类记忆；实际打开记忆详情看到“记忆点”；设置切到记忆处理后显示当前记忆处理、记忆提炼。截图实际查看。未点击模型验证/图谱创建或其他写入动作。热更新曾使CUA绑定失效，重取当前应用后继续；一次工具等待超时，未据此判产品故障。

验证：sh scripts/go.sh test ./... -count=1通过4.874s；vet及git diff --check通过。首次检查4个断言仍匹配旧Tab/placeholder/导航名，已更新显示预期；路由/搜索等内部知识值未改，全量复查通过。产品与设计入口已加最新命名规则，历史文档不批量改写。
