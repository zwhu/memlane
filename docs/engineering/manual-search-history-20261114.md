# 最近搜索：只记录搜索弹框的主动输入

用户澄清：“我说的搜索历史，是我主动点开搜索弹框，输入的内容”。此前将官方搜索历史直接用于候选的理解已撤回，不作为本需求的交付。

范围：总览“近期动态”新增“动态／最近搜索”切换。最近搜索仅从搜索弹框输入变更产生，回车或关闭弹框（含选择结果后关闭）时保存最终非空词；同词移至最近，最多100条，显示时间，展开在原区域滚动。未输入的默认最近内容、Agent自动搜索与召回、分类切换和后台请求均不产生记录。历史按本机服务与认证身份隔离，0600客户端状态文件原子替换，应用重开后保留；不保存搜索结果或知识副本。

此前未记录输入入口，官方历史也无法可靠区分人工和自动调用，因此不回填历史。从本次更改开始记录。原“动态”官方活动流保持。

主流程：打开弹框→输入→回车或关闭→最近搜索展示→重开客户端读取；空词不产生条目，同词更新时间；其他服务身份不可见；展开与收起不撑长页面。数据只读来源已改为本地客户端状态，最近搜索不请求官方历史接口。

验证：`sh scripts/go.sh test ./internal/simpledesktop -count=1 -timeout=120s` 最终通过。新增覆盖真实输入控件键入并关闭、持久读取、重复／空词、身份隔离、两尺寸历史日期和展开高度。实际Native已核对类型切换与新列表空态，自动调用记录不混入；未为验收向日常历史加入假搜索词。完整的日常手动输入保存依靠隔离UI测试验证，未声称日常新增记录实窗验收。

问题留痕：切换控件使短列表溢出的问题累计两轮定向检查失败；官方Segmented保留，紧凑主题与标题下间距调整后通过，计数保留2，不新增第4轮失败。前候选直接使用官方历史接口时，字段驼峰与活动接口不同导致时间／项目未知，实窗发现1轮；该数据源随用户澄清整体撤回，最终实现无此接口。曾有一次全包检查在并行修改的搜索键盘用例失败，最终同包全量已通过，不将其合并为本需求失败。

本轮仅dev源码与检查，保留共享工作区其他修改，未启停后台、调用模型、修改插件或打包。

## 空态位置缺陷修正

用户截图指出“暂无搜索历史”悬在面板外、下方仍有大空框。该具体问题累计失败1轮，新增几何断言同轮复现：文字Y=492.553，面板Y=506.686，明确在框外。已证根因是空态、加载及错误提示作为面板的兄弟节点排列，而非面板内状态；此前只检查文字存在，遗漏位置验收。

现将无内容时的空态／首次加载／读取失败统一放入面板内居中区域；空态显示淡色搜索图标、标题及一句引导；失败提供重试；已有内容刷新失败时提示留在面板内部，不推动面板顶边。原有两栏高度及内部滚动约束保持。`TestOverviewHistoryEmptyStateStaysInsidePanel`先失败后通过，所有`TestOverview`通过；实际Native已核对最近搜索空态截图，文字及图标位于框内居中，两栏内容顶边重新对齐。准备时误用SDK文本对齐常量导致一次编译失败，改为官方`ui.Center`；不另计产品验收轮次。

## 用户最新收口：固定列表与删除重复入口

覆盖本文此前展开／收起规则：最近知识最多20条，近期动态与最近搜索显示最多50条，两栏列表均固定320 DIP高并独立纵滚；删除知识分页、动态展开／加载更多及“搜索知识”按钮，搜索统一走顶栏。热力图选日期仍可筛选知识并返回最近知识，切换日期重置知识区滚动。

知识条目左右各14 DIP内边距，图标、标题与箭头不再贴边；两栏使用同高度、同圆角的边界，知识列表补齐轻边框和滚动边缘渐隐，删除旧独立顶线及条目圆角分隔线。用户对固定滚动初稿的底部收口提出一次视觉反馈，当前通过统一边界修正；不并入历史短列表溢出或空态计数。

定向测试改为固定高度、20／50上限、双尺寸顶底对齐、两栏独立滚动、少量内容不缩高和无旧按钮。首次几何断言将319.99997与320直接作等值比较失败，修正为0.1 DIP容差，属于夹具比较精度，不记产品失败。全包检查已通过，实际Native核对了去掉按钮、左右留白与固定列表。未新增假数据到日常库。
