# 图谱页面整理与刷新稳定性

2026-11-15。用户要求重做所示代码图谱未开启页，先保持现有浅蓝／白色风格；随后指出知识／图谱切换来回闪、页签不齐，以及列表／图谱刷新闪烁。首页候选仍未获认可，本轮不改首页或重新定义图谱语义。

## 范围与连续操作

项目 → 知识 → 刷新列表 → 图谱 → 刷新图谱 → 代码图谱未开启态 → 返回知识。沿用日常库和官方组件，不开启代码索引、不调用模型、不修改权限。源码热重载沿现有 watcher，不启停日常后台或构建完整包。

已实施：

- 知识、原始记录、图谱共用同一个外层页签宿主和稳定 Key，不再分别嵌在阅读分栏与图谱页内。
- 实体关系／代码图谱采用官方 Segmented。未开启时仅保留中央开启主按钮，移除无效的刷新与更新按钮；使用现有字体、浅蓝图标底与48px对齐底栏。
- 开启失败仍显示；未开启项目不展示全局缓存的“官方代码索引状态：…”历史运行回执。状态缓存目前是 App 全局字段，本轮没有将其改造为逐项目任务账本。
- 列表／正文的读取提示放入已有工具栏，图谱读取提示也留在固定工具栏；不再插入额外内容行。图谱刷新按钮、状态与 WebView 使用稳定 Key。
- 同项目同数据组的图响应与上一响应字节相同，不再发布新frame。不同数据仍发布；原epoch／项目隔离检查在相同数据判断之前，不放过迟到结果。
- 刷新图谱保留原节点选择，成功返回后用当前节点表重新核对：节点消失则清除，仍存在则更新其原始字段。导航和模式切换仍清除旧图及选择。
- 列表发布前，明确相同版本的知识或更新时间相同的会话保留已解析标题／摘要，标题读取继续核对；不复制原始正文。未知文档版本、明确版本变化或权限身份失效不沿用此快捷路径。
- 后续截图暴露共同导航移出 Split 后的分隔线回归：导航按同一个 ProjectListWidth 保留分栏边界，阅读页分隔线向上接至页头；图谱工具栏与原始记录筛选统一为垂直12、水平32内边距。
