# 保存结果未知异常归档

用户授权“归档此异常”：结束提醒，保留原材料与未知状态，不宣称保存成功，不重发。使用 plan-change-impact / verify-continuous-scenarios。

实现范围：已验证安装的官方只读 pending 投影增加每条未知记录的摘要标识；Native 在现有客户端状态目录持久化这些标识、会话身份、数量、时间，不保存正文、不修改官方队列或Agent配置。按精确条目标识扣除已归档部分，新增普通/未知记录继续提醒；历史入口可展开查看。没有服务接口、模型、数据迁移或release变更。未知投影不完整/存储失败不隐藏提醒。

连续用例：同会话20未知→归档→活动计数/侧栏减少20→历史可见且仍未知→重新打开仍归档→新增普通和未知记录仅新项提醒；读取/写入归档失败保留活动项；官方buffer字节不变、无POST/重发。Python投影夹具、Go持久化/混合计数/UI交互、实际日常库/Native分别验证。原SAVE-CHECK01等失败计数保留，不跑模型实验。
