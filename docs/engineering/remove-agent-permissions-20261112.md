# 移除项目／Agent 权限管理

状态：开发已暂停，尚未全量清理或验收完成。当前统一入口见[暂停交接](coding-memory-handoff-20261112.md)。继续 coding-memory／官方代码图谱目标，不重做已有界面。

2026-11-12 用户原话：「我现在把所有跟权限管理相关的能力全部去除，本阶段不考虑跟权限相关的事情」「所有代码，文档，全部清除掉，默认所有agent都能写，都能读取」。侧边对话已明确转交主线程执行。

## 当前规则

- 所有已连接 Agent 都能读写所有项目与通用知识；不设项目／Agent 白名单、角色、读取复核、授权或撤权操作。
- 项目／dataset 仅作数据归属与检索分组。默认检索可按当前项目提高相关性，选择其他项目不需要许可；未指定保存目标时仍需确定存放位置。
- 保留服务连接认证：验证所连接的本地服务／账号与有效连接代次，拒绝错误或已断开的连接身份。认证不产生项目级或 Agent 级读写授权表。官方 SDK 自身账号／dataset API 使用其既有认证，以共享服务接入满足所有 Agent 读写；不改写第三方 SDK 为匿名服务。
- 保留任务所有权、显式启动／停止、取消、去重、来源身份／版本及迟到结果核对。它们用于避免任务重复、错误来源和旧任务发布，不作为读写许可。
- 保留数据、来源和既有版本。清理功能代码不等于删除知识库、会话材料、有效运行依赖或既有停止问题的失败证据。
