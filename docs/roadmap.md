# 后续 Roadmap

这里只记录已提出的后续方向，不作为当前版本的实施或验收要求。首版继续按 [产品定义](product.md) 和 [实施清单](implementation-plan.md) 完成本机记忆闭环。

## 桌面端管理其他主机的记忆

- **记录日期**：2026-11-07，用户明确提出。
- **目标**：未来可在 Memlane 桌面端查看和管理其他主机上的记忆。
- **状态**：已记录，未设计、未排期；不纳入本次工程搭建和首版实现。
- **届时再确定**：主机连接方式、身份与权限、主机和项目的展示关系、离线/断连行为、可执行的远程管理操作。
- **范围说明**：远程管理不自动包含主机之间的数据同步、合并或复制；是否需要这些能力另行讨论。

当前不为此增加远程端口、连接界面、认证协议或多主机数据模型。本机 UI 与业务服务继续按现有职责分离实现，未来在该边界上评估远程接入。
