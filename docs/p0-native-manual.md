# 原生窗口复查与后续辅助功能验证

系统红黄绿按钮、真实窗口拖动、按钮/正文拖动排除以及系统中文输入法候选窗与连续提交已通过真实系统事件验收。按用户最新指示，VoiceOver旁支本轮停止，未通过结果保留到后续增强；下列步骤仅保留用于复查，不能作为本轮继续操作的指令。布局、5000字符选择、Tab焦点移动与NSAccessibility暴露已通过，不能替代实际VoiceOver。

测试 App 为 `build/p0-ui-prepare/darwin-arm64/MemlaneUITest.app`，使用独立标识 `io.github.zwhu.memlane.p0.cfb0e56ff8ee` 和本轮合成临时目录；已准备真实引擎与模型，并保持主动停止。即使本机受控源已停止，已验证缓存仍可复用。这里测试的是草稿与系统界面，不需要启动记忆服务、连接 Agent 或保存真实内容。

1. 打开该 App，点击“新增记忆”。仅输入合成文字：`P0 人工验收：中文输入 request_id 与版本恢复`。切到 macOS 系统中文输入法，用拼音输入“项目经验”，确认候选窗出现在正文插入点附近，选词、连续输入、删除与切换页面后文本正确保留。
2. 用真实鼠标拖动侧栏顶部和正文工具栏空白处，确认窗口移动；点击输入框、按钮与侧栏导航时不应误拖动。记录是否正常及异常位置。
3. 点击黄色按钮最小化并从 Dock 恢复；点击绿色按钮进入系统缩放/全屏并返回；点击红色按钮隐藏窗口，再从菜单栏“打开 Memlane”恢复。确认过程中 App 未意外退出、草稿保留。
4. 后续辅助功能增强时再开启VoiceOver；本轮已停止该项。未来复查可使用其导航读出侧栏“总览/全部记忆/设置”、正文“记忆内容”及准备/更新按钮。确认控件名称和角色可辨、焦点可移动，能进入和编辑合成正文；保存禁用状态应被读出。结束后恢复原先的 VoiceOver 状态。
