# 技术原理动画制作经验与 2D / 3D 工程指南

本文沉淀自 [Memlane × Cognee 3D 记忆流转图解](../architecture/memory-flow-3d/README.md) 从文字流程图迭代到离线 60fps 3D 双风格动画的实践经验，总结**面向非技术/跨职能读者的技术原理动画**设计原则、3D 制作配方、2D 替代工程方案与常见避坑清单。

## 一、核心反模式与设计原则（从“PPT 卡片”到“真正的技术动画”）

### 1. 三个最容易踩的坑
1. **用“会平移的文字卡片”冒充动画**：把大段文字塞进白卡片里，切镜头时用 `opacity: 0→1` 蹦出下一段——观众全程在**读字**而不是**看画面**，复杂度并不会因加了平移运镜而下降。
2. **用“离散步骤 + `setTimeout` + CSS Transition”拼凑流程**：镜头运动与内部特效各自计时，既容易脱节卡顿，也无法像视频一样按住进度条丝滑倒放/快进。
3. **凭直觉画原理，没核对源码**：例如误把按标点切段说成“AI 语义切分”、误以为总结代替原文、或漏掉“召回是否调大模型 / 调哪类检索”。

### 2. 五条落地原则（借鉴 3Blue1Brown、Kurzgesagt、bbycroft.net/llm）
- **Show, don't tell（物体变形替代文字堆砌）**：让抽象数据变成有形状、颜色和重量的实体（纸飞机、信封、砖块、彩色积木、发光球、连线），用**折叠、切割、翻转、发射、扩散**讲清原理；文字退居屏幕底部只做 1–2 行极简字幕。
- **真实产品锚点 + 可选源码层**：所有真实组件直接贴官方产品图标，建立一眼识别的视觉锚点；默认讲大白话，把函数名/文件路径收进右上角「源码对应」开关。
- **把微观黑盒演出来**：讲 AI 记忆和向量时，必须同时演清 **切段（Chunking，规则切长文）** 与 **分词（Tokenization，词元拆成彩色积木并翻转露出词表 ID）**，否则外行永远不理解“中文怎么变成了坐标”。
- **把“谁在做”和“谁没做”都演出来**：把大模型做成独立的实体角色（如悬浮的 3D GPT 神经舱 + 代理光弧）；提炼和抽图时它亮起旋转，召回时它**保持灰暗休眠**，无需长篇文字就能反证“召回零大模型”。
- **先查源码再画图，简化必须明示**：所有顺序和调用边界先核对现行代码；若为减少重复画面做了合并（如将双线流水线合演），必须在字幕与 README 中如实标注真实执行顺序。

## 二、60fps 连续时间轴与运镜工程（2D / 3D 通用）

### 1. 单一主时间纯函数 `render(t)`
摒弃 `setTimeout` 链与离散状态机，将整部动画定义在唯一连续时间标量 `t ∈ [0, TOTAL]` 上：
- **每个动作都是 `t` 的纯函数**：例如 `remap(t, a, b)` 映射到 `[0, 1]`，再叠加缓动（`smoothstep`、`easeOutBack`、`easeInOutCubic`）驱动位置、旋转、缩放、管道绘制进度（`drawRange`）与打字机字符数。
- **天然支持视频级拖拽**：鼠标按住进度条任意拖动或倒放时，所有物体与运镜严丝合缝同步回退，零状态残留。

### 2. 弹簧阻尼导演机位 + 自由探索共存
- **导演轨**：按章节定义 `{ pos, look, orbit }`，章末 1.2s 自动做 `smootherstep` 平滑过渡，章内叠加轻微正弦漂移增加空间视差；遇到跨区域飞行（如晶体飞进 SQLite、段落进大模型再飞入图库）在章内做两段式机位衔接，确保起点与终点都在画幅内。
- **物理跟随**：真实摄像机每帧以指数阻尼 `k = 1 - Math.exp(-6.5 * dt)` 追赶目标位姿，切换章节或用户松手拖拽时毫无突兀跳切。
- **零重叠 3D 投影标签**：3D 节点投影到屏幕 2D 坐标后，每帧执行 2 轮轻量垂直松弛（AABB 碰撞推开），保证任意机位与自由旋转下标签绝不打架。

### 3. 离线运行与视觉闭环验收
- **零外部依赖、兼容 `file://`**：不要在离线 HTML 里用 `<script type="module" src="./...">`（会被浏览器 `file://` CORS 拦截）；使用经典 UMD 脚本 `vendor/three.min.js` + `vendor/icons.js`（Base64 Data URI 图标），双击即可零报错运行。
- **逐帧截图闭环自检**：用无头 Chrome 带 `--enable-webgl --ignore-gpu-blocklist` 按 `#t=...` 锚点截取所有关键帧并逐张目视检查，专门排查 5 类问题：**光照过曝/雾效发灰、前景柱子遮挡主角、透明物体背后串景、标签重叠、首尾全景左右裁切**。

## 三、3D 双视觉风格配方（浅色黏土 vs 深空发光）

通过统一的材质注册表（`clayMat` 自动登记原始参数 + `SPACE_PALETTE` 映射）与 `applyTheme(mode)`，单份代码可无损切换两套截然不同的 3D 美术风格：

| 维度 | 浅色工作室黏土风（默认） | 深空科技发光风（`?theme=space`） |
| --- | --- | --- |
| **适用语境** | 温暖科普、产品介绍、编辑风文档 | 发布会、技术分享、3Blue1Brown / bbycroft 风格演示 |
| **背景与地板** | `#F4EEE4` 暖米白棚拍背景 + 极淡圆点纸纹 + 轻雾 `FogExp2(0.0062)` | `#060914` 午夜深蓝 + 650 颗缓转 3D 彩色星尘 + 发光青蓝电路网格地板 |
| **光照与曝光** | 三点柔光箱（低曝光 `0.93` 防黏土发白），柔和投影 `PCFSoftShadowMap` | 高对比边缘光（`rimLight` 电光蓝紫 `0.88` + 青色补光），曝光 `1.16` |
| **材质与发光** | 哑光圆角黏土（`roughness 0.5–0.72`）+ 磨砂玻璃，零廉价塑料反光 | 曜石深蓝底座（`roughness 0.34, metalness 0.28`）+ 霓虹自发光导管 + 加法混合 `THREE.Sprite` 径向光晕（零后处理帧率损耗） |
| **动态画布** | 浅米白对话窗 + 浅蓝纸质登记表 | 暗色 OLED 对话终端 + 发光青蓝全息台账 |

## 四、如果用 2D 的话要怎么做？

如果不想引入 Three.js（追求单文件几十 KB 极轻体积、更高文字/图表锐度、或偏 Kurzgesagt / 3Blue1Brown 2D 扁平插画风），**同样绝不要回到“DOM 白卡片 + CSS 跳切”**，推荐采用以下 **2D 高帧率动画工程方案**：

### 1. 渲染栈选型
| 方案 | 适用场景 | 优缺点 |
| --- | --- | --- |
| **单张高 DPI HTML5 `<canvas>`（最推荐）** | 离线单文件、60/120fps 粒子/星图/传送带/物理形变、零依赖 | 性能极强、可任意缩放运镜不糊；手绘圆角与排版需封装少量绘制工具函数 |
| **Canvas（动效/星图/粒子）+ 极简 SVG/HTML（图标与字幕）** | 需要大量矢量产品 SVG 图标与锐利中文排版 | 兼顾 60fps 流畅度和文字清晰度；注意只用 `transform` 同步浮层，绝不触发重排 |
| **离线视频导出（Motion Canvas / Remotion / Manim）** | 要直接产出 MP4/GIF 放进 PPT、公众号或 B 站 | 逐帧确定性渲染，画质和音画同步最稳，但失去浏览器实时拖拽交互 |

### 2. 2D 下怎么做出“立体感与丝滑感”？
1. **统一虚拟 2D 摄像机（单次矩阵变换）**：
   维护平滑阻尼摄像机 `{ cx, cy, zoom }`，每帧在 `<canvas>` 顶部只执行一次：
   ```js
   ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
   ctx.translate(W / 2, H / 2);
   ctx.scale(cam.zoom, cam.zoom);
   ctx.translate(-cam.cx, -cam.cy);
   ```
   整个世界照样用单一连续时间轴 `draw(ctx, t)` 渲染，拖动进度条一样如丝顺滑。
2. **2.5D 伪立体视觉语言（Kurzgesagt 技法）**：
   - **厚边 + 柔和长投影**：每个 2D 卡片/积木先画一层偏移 `+6px` 的深色底边再画主面，瞬间摆脱干瘪平面感；或者直接用 **2:1 等距斜投影函数** `iso(x, y, z) => [x - z, (x + z) * 0.5 - y]` 在 2D Canvas 里画出精致的等距立体工厂！
   - **物理形变（Morph & Squash-Stretch）**：
     - 对话气泡沿对角线折叠收缩 → 变成三角形纸飞机沿贝塞尔切线飞出；
     - 闸刀落下瞬间，被切砖块横向微压扁再弹开成两块（`scaleY: 0.85 → 1.04 → 1`）；
     - **2D 分词翻牌（无需真 3D）**：用 `ctx.scale(Math.cos(angle), 1)` 把每个彩色词元积木在横向压扁到 0 再展开，过 `90°` 瞬间把正面的中文词 `清理` 换成背面的深色 `#4821`，视觉上就是丝滑的立体翻牌！
3. **2D 向量星图怎么做出空间层次？**
   - **三层视差（Parallax）**：远景旧记忆点半径小、透明度低、随摄像机移动幅度只有 `0.4×`；中景核心星团 `1.0×`；前景命中的绿光近邻 `1.25×` + 径向渐变光晕 + 同心扩散雷达圆环，肉眼立刻产生景深。
   - **余弦相似度可视化**：雷达波扫过时，在最近 3 个点与问题点之间实时拉出虚线并弹出动态相似度标尺（如 `0.94`），比干讲数学公式直观十倍。

### 3. 2D vs 3D 选型建议
- **优先选 2D Canvas / 2.5D 等距**：嵌入文档或移动端浏览、强调轻量单文件（`<30 KB`）、偏插画/扁平图表气质、不需要观众手动旋转视角。
- **优先选 3D WebGL（Three.js）**：展示天然具有三维直觉的概念（XYZ 向量空间星团、多层立体关系图、沙盘流水线），且希望观众暂停后**亲手拖拽旋转、放大凑近探索**。
