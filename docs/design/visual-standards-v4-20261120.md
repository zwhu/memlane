## 2. 设计原则

1. **原生 macOS 专业工具感**：参考 Things 3、Linear、Raycast。克制、高对比，信息密度适中，靠排版和细节体现质感。
2. **颜色只承载含义**：用中性灰阶，加一个强调色。状态色只用来表示状态，分类标签一律用中性灰。
3. **用分隔线和留白分区**：不再嵌套带边框的卡片，内容区也不浮在面板上。
4. **动效丰富但不拖慢操作**：常用交互用短促的弹簧；标志性的动画只出现在低频但有意义的时刻。系统开启「减少动态效果」时，一律直接到最终状态。

## 3. 设计令牌

数值都是逻辑 px，对应 MyGo 的 DIP（1 DIP ≈ 2 个截图像素）。实现时必须集中定义在一个令牌模块里，页面中不得直接写色值或字号。

### 3.1 字体

- 界面字体用系统字体（SF Pro，中文为苹方），代码用 SF Mono。不内嵌第三方字体。
- 字重一律显式指定（400／500／600）。不要用 `.Bold()`，它对应的是 700。

| 级别 | 字号 | 主要用途 |
| --- | ---: | --- |
| caption | 11 | 元信息、分类标签、召回标签、分组标题、角标 |
| footnote | 12 | 摘要、次要说明、按钮、菜单、列表项正文 |
| body | 13 | 导航、列表标题、控件 |
| reading | 14 | 阅读栏正文（行高 1.8） |
| heading | 16 | 区块标题、品牌名 |
| title | 22 | 统计数字（等宽数字） |

### 3.2 颜色

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| accent | `#5E6AD2` | `#7C86E8` | 选中、链接、主按钮、进行中状态、热力最高档 |
| accent-soft | accent 10% | accent 16% | 选中块、召回标签底色 |
| bg | `#FFFFFF` | `#1C1C1F` | 内容区 |
| bg-elevated | `#FFFFFF` | `#242428` | 菜单、悬停抬升的行 |
| sidebar | `rgba(244,244,246,.86)` 加背景模糊 | `rgba(36,36,40,.84)` 加背景模糊 | 侧栏材质 |
| fill-1 | `#F5F5F7` | `#26262A` | 输入框、行内代码 |
| fill-2 | `#EDEDF0` | `#2D2D32` | 分段控件底色、热力空格、分类标签 |
| border | `#E6E6EA` | `#2E2E33` | 分隔线 |
| border-strong | `#D5D5DB` | `#3A3A40` | 控件描边 |
| text-1 | `#1B1B1F` | `#EDEDF0` | 主文字 |
| text-2 | `#55585F` | `#A8A9B0` | 次要文字 |
| text-3 | `#7A7D85` | `#808189` | 元信息 |
| text-4 | `#A3A6AD` | `#5C5D64` | 占位、禁用、召回 0 次 |
| ok | `#2E9E5B` | `#3FBF73` | 成功状态（只用作圆点或图标） |
| danger | `#D64545` | `#EF6363` | 失败状态（用作圆点及失败原因的文字） |

- **热力图**：用 accent 的透明度分四档，浅色为 22%／42%／68%／95%，深色为 25%／45%／70%／98%。
- **Agent 图标**：保留各自的品牌色，这是「颜色只承载含义」原则下唯一的例外。
- **主题**：深浅两套跟随系统外观切换，强调色在两种外观下都固定，不跟随系统强调色。

### 3.3 间距、尺寸与圆角

- 网格以 4 为基数：4／8／12／16／20／24／32／40。
- 圆角统一为 6；小元素（标签、热力格）用 4 或 2；菜单用 8；窗口为系统圆角。
- 尺寸：单行列表 32，双行列表 52–56，标题栏 52，侧栏宽 220，项目列表栏宽 360，阅读栏正文最大宽度 680。
- 窗口默认和最小尺寸都是 1200×820，允许放大。

## 4. 布局

### 4.1 窗口骨架

- **侧栏**（220，半透明材质）从上到下依次为：系统红绿灯、品牌，然后是总览、通用记忆、用户画像，接着是项目区（标题行带「全部 N」和「＋」，项目行右侧显示未读数），最底部是全局设置、服务状态入口（鼠标悬停弹出组件状态小浮层、单击直达「设置 › 服务」，见第 7.5 节），以及右下角外观快捷切换图标（左键浅色／深色实时切换，右键可选「跟随系统／浅色／深色」；设置页「记忆提炼」中也提供同等三态分段控件）。
- **侧栏行为**：选中的导航项用 accent-soft 色块标示，色块在导航项之间以弹簧滑动；选中项的图标换成实心。点击未读数字会进入该项目，并自动打开「仅未读」。
- **标题栏**（52）与内容区融为一体，不再有灰色窗口底色和白色浮起面板。标题栏左侧放当前页的标题或项目名，项目页还显示路径；右侧放全局搜索「搜索记忆与原始记录 ⌘K」（不再在项目顶栏放置重复的「项目设置」按钮，项目级配置收口到项目标签栏的「管理」标签）。内容滚动后，标题栏底部才出现分隔线。

### 4.2 首页

1. **记忆分布**：标题行左侧是标题和日期范围，右侧是三项统计（已使用天数、记忆数、原始记录数，竖线分隔）。下方热力图格子 11px、间距 3，不加卡片框；右下角放「今天新增 N 条」和图例。
2. **双栏主体**：「最近记忆」（宽度比 1.6）和「近期动态｜最近搜索」（比例 1，最小宽 280）用竖线分隔，两栏占满剩余高度、各自滚动，不固定列表高度。
3. **去掉的内容**：项目入口区和欢迎标题。
4. **最近记忆每一行**：左侧是 Agent 图标；中间正文为最多 **2 行** 行内 Markdown 富文本（行内代码使用 `SF Mono` + 圆角胶囊底色，支持粗体、斜体、删除线、链接文案，超长截断）；下方元信息行依次是未读点、项目名、召回标签、分类标签、日期。悬停时行抬起 1px 并显示阴影，同时隐藏自身顶部和下一行顶部的分隔线，右侧出现箭头。点击后进入该项目的三栏，并选中这条记忆。
5. **近期动态**：时间线左侧用状态圆点（仅「处理中／已启动」显示进行中方块动效，历史「搜索记录」保持静默中性圆点）；失败按来源合并成「×N」，并提供「更多」。自动召回事件整行可点击（不额外占一行「查看 N 条记忆」），进入对应项目并带上「本次召回」筛选。

### 4.3 项目页（三栏）

- **列表栏**（360）从上到下依次为：
  - 下划线标签「记忆／原始记录／图谱／管理」，下划线以弹簧滑动；
  - 筛选工具条（记忆页）或「全部／会话／文档」紧凑分段控件（原始记录页）；
  - 列表项：记忆为最多 3 行行内 Markdown 富文本 + 元信息行；原始记录会话为固定 2 行主题槽（无裸 UUID 抖动）+ Agent 图标 + 「会话」标签 + 覆盖轮数 + 日期；
  - 底部状态栏，显示「已载入 N 项」和分页。
- **选中**：选中项用 accent-soft 色块标示，按 ↑↓ 可以切换选中项。
- **阅读栏**从上到下依次为：
  - 元信息行：Agent、项目、日期、召回、分类；
  - 正文：reading 字号，行高 1.8；
  - 「记忆点」：分类规则，以及哪些字段未记录；
  - 「出处 · 来源会话」：展示可识别的会话标识，点击「查看来源会话」（带加载态）在**右侧阅读栏原位切入来源会话**，保持左侧记忆列表不中断；顶部展示 V4 来源返回条（`← 返回来源记忆` + 摘要 + 可选「在原始记录中打开」），下方以 V4 分段控件切换「问答／工具记录」和可折叠工具卡片；
  - 底部状态栏：「Cognee 提供 · 只读」，以及「复制正文」按钮。

  各区块之间只用分隔线，不使用填充色块。

### 4.4 筛选（已确认）

- 筛选工具条只有一行，左侧是「分类」下拉和「仅未读」开关，右侧是排序下拉。
  - 「分类」下拉包括「全部」和 7 个官方分类：项目状态、踩坑经验、项目约定、代码位置与关联、代码变更、约束条件、其他。每项显示在当前「仅未读」和「本次召回」范围内的条数。
  - 选了某个分类后，按钮切换为强调色描边的「已筛选」样式。
  - 排序下拉有「按时间」和「按召回次数」两项。召回次数还没确认时，「按召回次数」不可选，并说明原因。
- 列表栏里不放文字搜索框，关键词搜索统一走全局 ⌘K（可以把范围限定为当前项目）。
- 从召回动态进入项目时，工具条下方显示「本次召回 · N 条」筛选条，带「显示全部记忆」和「返回动态」。
- 没有符合条件的记忆时，显示空态，并保留所有筛选控件，方便直接修改条件。

## 6. 动效

架构沿用 [MyGo 动效契约](motion-implementation.md)：动画只读取真实状态，不能用动画结束来宣布任务完成，绘制回调里不执行任何业务操作。

| 档位 | 参数（Duration, Bounce） | MyGo 预设 | 用途 |
| --- | --- | --- | --- |
| smooth | 0.35s, 0 | `ui.Smooth` | 页面淡入加 8px 位移、列表错开入场（间隔 28ms）、阅读栏切换 |
| snappy | 0.30s, 0.15 | `ui.Snappy` | 侧栏、列表、分段控件的选中块，标签下划线，悬停抬起，下拉菜单 |
| bouncy | 0.42s, 0.30 | `ui.Bouncy` | 热力图按周生长（每周延迟 9ms）、点击某天的缩放反馈、新记忆落入、角标跳动、开关圆钮 |
| fast | 120ms 线性 | `AnimateColor` | 悬停和选中时的颜色过渡 |

几个标志性的时刻：

- **新记忆入库**：整理进行中，动态里显示方块舞台动画。**收到服务回执之后**，新记忆才落入列表：行高展开、下落回弹，背景闪一下后淡出；同时今天的热力格跳动，侧栏角标跳动。
- **空态**：三个方块漂浮，并随指针轻微视差。

系统开启「减少动态效果」时（`c.Preferences().ReduceMotion`），以上全部直接跳到最终状态，自绘循环也停止请求下一帧。

## 7. 剩余页面与扩展组件（2026-11-21 v2 确认）

本节沉淀 2026-11-21 访谈决议与 HTML 交互稿 R2 评审结论，覆盖配置型页面、⌘K 与检索结果页、统一弹窗/菜单、项目权限管理、服务状态浮层、用户画像与首次启动向导。

### 7.1 分组列表（设置 / 项目「管理」/ 服务）

- **去带框卡片**：所有配置型页面不再使用带边框卡片嵌套，统一改为居中最大宽 `680` 的「分组列表」。
- **结构**：每组由 `caption` 分组标题（可选右侧状态说明或描边小按钮）+ 顶部发丝线 + 发丝分隔行组成。单行高 `32`、带次要说明的双行高 `52`，左侧标题与说明，右侧放控件或等宽值。
- **控件映射**：开关统一用 `v4Switch`；多选一用 `v4Segmented`（弹簧滑块）或 V4 下拉，不再使用原生 Checkbox / Radio；去掉「文字链 ›」操作，改为描边小按钮或整行可点 + 行尾箭头（`›` 仅作导航行尾指示，不与文字链混用）。
- **设置页标签与文案改名**：
  - 顶部下划线弹簧标签为「记忆提炼／Agent 与模型／服务」，「记忆提炼」中包含外观三态分段（与侧栏右下角按钮实时同步），并保留设置页 `Segmented` / `Modal` 既有契约。
  - **界面全面去除「补全桥 / bridge」与过时通道术语**：
    - 提炼来源两档分段定名为「**用已连接的 Agent 提炼**」与「**直接调用模型 API**」；
    - 前者说明：`让 Codex、Gemini 等已连接的 Agent 用它自己的模型和额度提炼记忆，无需填写 API Key`；
    - 后者说明：`填写 OpenAI 兼容或 Ollama 等接口，由 Memlane 直接调用`；
    - 服务状态浮层、服务页与日志中的对应组件统一称为「**Agent 模型代理**」。
  - Provider 表单中未配置的采样温度 / 最大输出 Token 保持省略，用户显式填写的 `0` 必须保留。

### 7.2 ⌘K 单栏命令面板（移除独立「检索结果」页）

- **单栏收口决议（2026-11-21 v3）**：正式移除独立的「检索结果」三栏页面、`⌘↵` 快捷键与「查看全部结果」按钮，所有全局检索统一收口在 `640px` 单栏 ⌘K 浮层内完成。
- **⌘K 命令面板（Raycast 式）**：宽 `640`、距窗口顶部约 `120`、`bg-elevated`、圆角 `8`、遮罩淡入 + `snappy` 缩放入场（`0.96 → 1`）。
  - **检索范围**：统一覆盖项目记忆、通用记忆与原始记录；输入栏下方为筛选条：`v4Segmented`「全部／记忆／原始记录」+「仅当前项目」范围芯片（从项目页打开时默认勾选，勾选时排除跨项目通用记忆；从总览等页打开时默认不勾选）。
  - **上下文记忆与清空**：再次打开 ⌘K 时恢复上次的查询词、筛选条件与选中项，便于连续排查；点击输入框右侧 `×` 按钮清空当前查询（空查询时隐藏 `×`）。
  - 结果行复用项目列表行风格：左侧 Agent 图标，主体 2 行行内富文本（带关键词高亮 `--mark-bg`），元信息行依次展示未读点、项目名（或通用记忆分类）、召回标签（或原始记录类型/轮数）、分类标签与日期；**原始记录始终展示可读会话主题，不暴露裸 UUID**。
  - 空查询展示「最近记忆 / 最近原始记录」分组；搜索加载中展示骨架行。
  - 键盘交互：`↑↓` 驱动弹簧选中块并滚动可见，`↵` 直接跳转打开当前项（项目记忆进入项目三栏、通用记忆进入通用记忆三栏、原始记录进入项目原始记录页；IME 组合输入 `isComposing` 时不误触），`Esc` 关闭；底栏展示快捷键提示。

### 7.3 `v4Dialog` 与 V4 下拉／右键菜单

- **`v4Dialog`**（基于 `ui.Modal`，保留设置页弹窗契约）：
  - 提供 `480`（确认、改名、小型表单）与 `640`（Provider 编辑、手动导入画像、安装清单、环境详情）两档宽度；背景 `bg-elevated`、圆角 `8`、遮罩淡入 + `snappy` 缩放 `0.96 → 1`。
  - 打开时自动把焦点移入弹窗（无内部聚焦控件时聚焦面板自身），关闭时恢复原触发元素焦点；`Esc` 取消。
  - 底栏右对齐「取消 + 主操作」；普通确认弹窗绑定 `↵`；**删除类危险弹窗**主按钮用 `danger` 底色并写明具体动作（如「删除此配置」），**不绑定 `↵` 确认，且拦截回车防止击穿触发背景按钮**。
- **V4 下拉与右键菜单**：圆角 `8`、`bg-elevated`、菜单投影 `--shadow-menu`、`snappy` 缩放弹出，菜单项悬停 `accent` 高亮并支持勾选标记与右侧计数/快捷键；右键通知菜单与外观三态菜单统一使用该样式。

### 7.4 项目「管理」标签、三档权限下拉与消息模块

- 采用分组列表（居中最大宽 `680`），自上而下固定包含：消息与采集状态、项目信息（名称 + 编辑名称弹窗、等宽路径 + 复制）、Agent 访问权限、工具记录关系图谱。
- **三档权限下拉**：每 Agent 一行，右侧三档下拉「不可访问／只读／读写」，保留「写依赖读」语义；选择后立即保存并显示转圈加载态，失败时自动回滚到原档位并在控件下方展示 `danger` 错误文案（需要时提供重新核对）。
- **工具记录关系图谱**：使用三态 `v4Segmented`（跟随全局／开启／关闭）+ 描边按钮「创建工具图谱」（弹窗确认）。
- **消息与采集状态（2026-11-21 修订）**：
  - **固定顶部位置**：固定置于项目「管理」页最上方；当状态全部健康时原地收敛为单行紧凑发丝提示行，有进展或异常时原地展开，不再随状态变化在顶部与底部之间跳动。
  - **三桶收敛与历史折叠**：所有项目级消息收敛为 3 个清晰分组——**「需要你处理」**、**「系统异常」**与**「进行中与待提炼」**，下方附可折叠的**「已知晓的历史提示」**。正常后台进行中状态（`待采集`、`处理中`、`等待接续`）及中性状态（`已保留`、`操作记录`、无可恢复消息的手动 `已暂停`）归入**「进行中与待提炼」**（不计入橙色「N 项待处理」异常数，也不显示「知道了，不再提醒」）。
  - **去卡片单行发丝布局**：全部条目采用单行发丝分隔布局，禁止嵌套带阴影卡片；行内直接提供实际操作入口（真实异常与需处理条目附「知道了，不再提醒」／「暂不处理」与「恢复提醒」）。
  - **详情与队列阅读**：点击条目查看详情或本机消息摘要时，统一在 `640` `v4Dialog` 中呈现；待提炼队列中的文档内容使用 V4 发丝风格阅读区展示。

### 7.5 服务状态悬停浮层与「设置 › 服务」页

- **侧栏悬停浮层**：鼠标悬停侧栏左下角「服务 · 已连接」约 `300ms` 弹出状态小浮层（圆角 `8`、`bg-elevated`、`snappy` 弹出），列记忆引擎（Cognee）、接入网关、Agent 模型代理、磁盘空间的状态圆点与等宽指标；移入浮层保持不收起，移出触发区与浮层约 `200ms` 后收起；键盘聚焦同样展示、`Esc` 收起。**单击「服务 · 已连接」不保留浮层，直接跳转「设置 › 服务」**（浮层底部亦保留「在设置中查看详情」入口）。
- **「设置 › 服务」页**：按分组列表展示「组件状态」（状态圆点 + `SF Mono` 等宽指标，检测中显示骨架行）、「诊断」与「运行环境」；日志默认折叠在「诊断」区，展开后以 `SF Mono` + `fill-1` 底色呈现脱敏日志（支持切换原始日志），并保留单处「复制诊断」按钮。

### 7.6 用户画像

- 左侧来源栏宽 `216`，按来源分组，每行为双行（名称 + 更新日期·自动/手动方式），**不再统计或展示 `N 条记录`**，支持 `↑↓` 弹簧选中块切换；右侧阅读栏切换采用 `smooth` 淡入。
- **统一 V4 Markdown 原文阅读（2026-11-21 v3 回调）**：阅读栏顶部放元信息行（仅展示更新日期与自动／手动导入方式），正文最大宽 `680`（`readerMaxW`），按统一 V4 Markdown 样式（`14px` / 行高 `1.8`）原样渲染；**不再按 `[YYYY-MM-DD]` 强行拆分日期列或改写原始正文**。
- **中文五分类导出提示词**：手动／自动导出提示词提供「协作指令 / 个人身份 / 职业经历 / 核心项目 / 通用偏好」五个中文结构引导分组，仅作为生成时的结构参考，保存与展示时不得篡改模型输出的原始内容。
- 「重新导入／手动导入（`640` `v4Dialog`）／复制正文」统一放底部状态栏；失败态底栏主操作按钮与提示文案统一显示「重新导入」。

### 7.7 首次启动向导

- 保留「准备环境 → 连接 Agent → 配置记忆提炼」三步左步骤栏 + 右内容流程契约（隐藏主应用侧栏）。
- 左侧步骤栏（宽 `220`，半透明材质）使用弹簧选中块，已完成步骤显示绿色完成勾；右侧主体居中最大宽 `680`，依赖项按「运行基础／本地记忆引擎／Agent 接入」分组列表展示。
- 安装依赖与启动服务进行中复用方块舞台动效（`.stage.lg` / 自绘方块舞台），开启「减少动态效果」时直接停留在静态终态。
- 底部固定操作栏左侧放「环境详情」与提示，右侧放「上一步／继续」（末步为「启用并完成」）；「确认安装缺少的依赖」与「环境详情」均使用 `640` `v4Dialog`。

### 7.8 macOS 顶部状态栏图标与 300px 自定义 V4 弹层

- **状态栏模板图标**：macOS 顶部状态栏使用单色 4 格品牌模板图标（自动适配浅色／深色菜单栏）；仅当后台服务降级或任意项目存在未知晓的真实异常／需你处理提醒时，图标角部显示状态圆点（警告／异常色），正常进行中的 `待采集`、`处理中`、`等待接续` 与待提炼文档保持健康模板图标不变。
- **300px 自定义 V4 弹层**：点击状态栏图标弹出宽 `300` 的自定义 V4 面板，自上而下分为：
  1. **顶栏**：品牌图标 + 总体服务状态圆点与文案 + 快捷图标按钮（「打开主窗口」、「⌘K 搜索」）；
  2. **核心组件状态**：记忆引擎（Cognee）、接入网关、Agent 模型代理的紧凑状态圆点与等宽指标；
  3. **项目待处理提醒与进行中状态**：存在真实异常或需你处理提醒时按项目列出待处理数并支持单击直达对应项目「管理」页，无真实提醒时显示单行「所有项目消息状态正常」；存在活跃进行中工作或待提炼文档时，在下方独立以平静蓝色条目「进行中与待提炼（N 项进行中）」呈现并同样支持单击直达对应项目「管理」页；
  4. **快捷控制（双向同步）**：外观三态分段（跟随系统／浅色／深色，与主窗侧栏按钮及「设置 › 记忆提炼」实时双向同步）、「退出时保持后台运行」开关（默认开启，与「设置 › 服务」双向同步）、「登录时静默启动」开关（接入系统登录项；非 `.app` 开发直接运行模式下保持关闭并如实展示受 macOS 限制的说明）；
  5. **底栏退出操作**：根据保活开关显示「退出界面（后台保活）」或「退出并停止服务」，另提供「彻底停止并退出」入口，触发 `480` 危险确认 `v4Dialog`（不绑定 `↵`）后才停止后台服务并退出。

### 7.9 通用记忆 V4 三栏与项目「图谱」Native 外壳

- **通用记忆 V4 三栏与原位编辑器**：
  - 沿用 `360` 列表栏 + `680` 正文阅读栏骨架；列表栏顶部提供「全部／个人偏好／通用经验」分段筛选与新增入口，列表项复用行内 Markdown 富文本 + Agent 图标 + 中性分类标签 + 召回标签 + 日期。
  - 阅读栏正文采用统一 V4 Markdown 排版，下方「适用条件」与「原始来源」以发丝分隔区块呈现，不嵌套带框卡片。
  - 新增与编辑直接在右侧阅读栏内以 **V4 原位编辑器** 完成（分类分段、标题/正文输入、可折叠附加信息与底栏保存/取消），不再弹出割裂的独立编辑页。
- **项目「图谱」Native V4 外壳**：
  - 图谱页顶栏工具条（视图切换、刷新/状态操作）、待提炼文档发丝提示条（「有 N 份文档尚未提炼进图谱 · 可在『管理』查看」）与空态（三个漂浮 accent 方块 + 视差说明）统一采用 V4 令牌与组件。
  - 中间嵌入式官方 Cognee WebView 图谱画布保持 `#0E1526` 深色底色不变，仅规范其外围 Native 外壳与交互状态。

## 8. 验收方法

- 每次界面改动都要与原型对照，在实际 Native 窗口中检查 1200×820 下的**浅色和深色**两套外观，并检查「减少动态效果」打开后的效果。
- 检查顺序：先核对结构和层级，再核对令牌值；数值偏差在 2 DIP 以内视为通过。
- 不得为了凑「通过」，删掉规范中的组件或状态，再称其为「轻微差异」。实现上做不到的地方，要记录具体缺口，并在实施记录里标注。
