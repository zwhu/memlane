# 项目权限管理规格

日期：2026-11-13。状态：待评审规格，未实现。依据：[产品方案](project-access-product-plan-20261113.md)；实现依据：[技术方案](project-access-technical-plan-20261113.md)。PA 为本次需求编号，不是历史失败编号。

## 对象及字段

| 对象 | 必需信息与约束 |
| --- | --- |
| 项目 | 稳定 project_id、名称、路径别名、知识 dataset ID、可选代码／会话伴随组、登记来源；名称不作身份 |
| Agent 接入 | 稳定安装／配置实例 ID、官方独立主体；同一品牌不合并凭据，session ID 不充当权限主体 |
| 默认策略 | 访问级别、自动采集、自动处理、单调修订号；访问级别为不可访问／只读／可写并维护 |
| 项目覆盖 | 按 Agent 与字段保存显式覆盖；字段缺省表示继承，而不是 false |
| 生效状态 | 期望修订、官方已核对修订及结果；未知、部分成功不得显示已生效 |
| 通用知识 | 独立 dataset、个人偏好／通用经验分类、官方对象 ID、正文、适用条件、来源 |

## 功能要求

| 编号 | 可观察行为 |
| --- | --- |
| PA01 | 新仓库无需先添加或逐项目授权；管理侧按默认策略建立关联与有效权限，首次内容保存前确定目标 |
| PA02 | 默认策略按产品方案初始化；用户修改后更新仍继承的字段，具体覆盖不变；恢复默认立即回到当前模板 |
| PA03 | 不可访问无内容 read/write/delete/share；只读仅 read；可写并维护为 read/write/delete，不授 share |
| PA04 | 自动采集有效条件为有写维护权限且项目与 Agent 自动采集均开启；无效时在读取新正文和入队前跳过 |
| PA05 | 自动处理需可写维护且处理开关开启，覆盖 cooldown、idle、退出同步等自动触发；手动操作另查权限 |
| PA06 | 主动保存被禁时明确返回“当前 Agent 没有此项目的写入权限”，不改身份、不换组、不创建 owner 副本 |
| PA07 | 收到官方403后阻塞对应待发材料并停止自动重试；恢复权限不自动补交，用户可明确补交或丢弃之前合法采集的材料 |
| PA08 | 手动新建与自动发现共用身份；关联已存在项目不重置覆盖、重复建组或放宽 ACL |
| PA09 | 桌面自动发现项目，错误时保留已有目录并说明状态；允许空项目、未知归属不得猜测进入上一个项目 |
| PA10 | 通用知识可阅读、搜索、新增、编辑、删除，官方保存和处理结果分别表达；另一项目后续会话可召回可读通用知识 |
| PA11 | 项目明确约定优先于通用建议；不自动提升项目知识、不伪造来源；空项目仍可召回通用知识 |
| PA12 | 多 session 并发登记同仓库收敛为一个项目；同名不同目录不自动合并，代码／伴随／通用组不误列为项目 |
| PA13 | 关窗不影响后台登记和策略；重开后补发现；读取撤销后后续请求拒绝并撤下失效正文与复制入口 |
| PA14 | 活动任务取消按真实官方能力报告，停止后续触发不冒充已取消；已有部分写入保留且明确展示 |

普通不可访问规则针对 Agent，不代表桌面管理身份不能查看项目。自动采集／处理开关约束受管官方集成的自动行为；有写权限的用户主动请求仍可执行，不声称服务会禁止所有手动处理。

## 状态与时效

项目登记：未登记 → 登记中 → 关联完成／待核对；策略同步：期望已保存 → 同步中 → 已核对／未确认。界面不使用请求已发送代表已生效。

桌面活跃时每15秒刷新目录并在窗口重新激活时立即刷新；不承诺后台知识提炼在15秒内完成。每次材料读取／提交、处理触发及召回前查最新受管策略。撤权不追溯删除已进入模型上下文的内容，也不能宣称撤回请求已经发送的字节；保存回执应说明在途结果。

## 默认规则与冲突优先级

1. 项目对应字段的显式覆盖优先；否则采用当前默认规则。
2. 官方有效权限是实际访问边界，配置显示可写但官方拒绝时按拒绝处理并标记不同步。
3. 会话已固定的项目优先于临时工具 cwd；用户显式关联冲突返回可解释结果，不静默覆盖。
4. 管理侧只登记自己管理的官方数据组；Agent 自建的数据集不能凭名称替代项目知识组。

## 连续验收

- PA-A：默认允许 → 两会话首次打开新仓库 → 单一项目和官方组 → 正确采集 → 桌面发现 → 来源阅读 → 后续召回。
- PA-B：默认只读或采集关闭 → 新项目仍发现 → 自动不读新正文／不排队 → 主动保存明确拒绝或按实际写权限成功 → 编码正常。
- PA-C：项目覆盖禁写 → 修改默认模板 → 项目仍禁写 → 恢复默认 → 采用新模板；包含新 Agent 加入与旧凭据失效。
- PA-D：官方独立主体直接调用 raw、session、搜索、图谱、保存、更新、删除，验证允许／拒绝；检查角色继承和共享角色回退。
- PA-E：403、网络断开、部分授权成功 → 原操作及旧材料保留 → 无重试风暴、无切身份 → 明确核对及恢复。
- PA-F：手动新建后自动发现／相反顺序 → 去重；同名、符号链接、子目录、worktree 和目录移动按技术方案处理。
- PA-G：通用知识新增／编辑／删除 → 官方终态与内容一致 → 空项目及另一真实会话使用正确内容；无权时不注入。
- PA-H：关窗、重开、后台刷新与来源返回保留阅读状态；已有 item-fe 会话不被自动迁移。

固定方案参数与算法写在技术方案，验收验证是否实现这些规则。源码、协议、真实服务／模型及 Native 证据分开；本轮未执行产品验收，不改变历史失败计数。
