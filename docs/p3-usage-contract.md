# P3-U 使用记录与透明排序契约

2026-11-08，基于 P2 日常 Agent 与 C2/C3/C4/E/D 的受信服务。本文收口工程语义，U 已实现并通过本机真实App/pi/Rust验收，证据见 [U验证](p3-usage-validation.md)；不把接口成功/原型次数描述为已采集使用记录。

## 事实与覆盖范围

成功读取、检索返回和报告采用是三个事件：

- 日常 Agent 的 `memory_get` 成功读取其授权范围内一个具体当前版本，保留原契约中显式查看归档/删除状态的能力；读取不赋予有效性，采用只允许当前有效知识，记录该次服务成功；不会推断 Agent 实际用了正文。`memory_status`不计使用；连接验证单独计，后台整理次数显示未采集并引用已有冻结来源记录，不进入日常常用排序。
- 日常 `memory_search` 返回具体有效版本时，每个请求内同一 memory/revision 只计一次，重复 chunk 不增加条目次数。返回不代表读取或采用。
- 采用必须新增明确的受控回执入口，关联此前读取/返回的具体版本、连接/代次/工作区和稳定操作 ID；它是 Agent 明确报告采用，不代表客户端独立核验了代码提交。旧 Agent 没有该入口时显示未采集，不由读取数补造采用数。
- App 成功展示某条详情记录为浏览，去重键来自实际用户导航/版本；自动轮询和后台详情补读不重复算浏览。App 搜索、后台整理和连接验证分开显示，不冒充日常 Agent 使用。

保存最小元数据：事件稳定 ID、事件类型/通道、连接与代次（如有）、授权范围、memory/revision、观察 UTC 时间和回执关联；不保存查询正文、模型输入、推理或聊天。读取/返回回执保存受信服务解析的项目与规范worktree路径摘要；采用必须与旧回执摘要相同，身份未知不能采用。工作区验证沿用 P2 的显式 binding / pi ctx.cwd，不让模型工具参数伪造工作区。

开始采集时保存实际启用时间与版本，重启保留。之前的使用次数/采用/浏览为未知；采集以来未观测到的次数可为0，并标明覆盖起点。时间按系统实际 UTC 记录，显示可换本机时区，不导入旧聊天、不回填历史。

## 去重、保留与错误

事件按来源身份、代次、稳定请求/导航/采用操作 ID、类型、具体版本建立唯一约束。pi使用真实toolCallId；MCP SDK工具回调不暴露传输request ID时以桥的一次实际回调为一次请求，不推断断网重试是同一读取；采用使用Agent提供的稳定operation ID；同一 ID 的不同参数冲突。检索返回每版本一次；多次独立读取是真实多次服务使用。连接失效或范围/版本不允许的请求不能写成成功事件，错误与未采集数据也不写成0。

详细事件保留90天，常用窗口为近30天；服务启动、每小时和新观察提交时清理过期详细事件。最小幂等回执和内容摘要散列随数据库长期保留，防止事件清理后重放ID重复计数；回执不保存查询正文或知识正文，新采用只关联90天内的匹配读取/返回。依据是本机轻量存储和近期开发上下文；它们是本切片明确工程选择，不是原型授权。只清理使用元数据，不清理知识、版本、出处、审核决定和活动事实。界面说明滚动窗口与覆盖起点；恢复备份保留其真实采集覆盖，不生成缺失历史。

## 排序与说明

不引入综合质量分数，也不改变向量检索的来源/真实性含义。

| App 排序 | 口径 | 并列规则 |
| --- | --- | --- |
| 最近更新 | 当前版本在本机持久写入时间，包括手动编辑/恢复；不是原文作者日期 | 更新时间降序、memory ID稳定次序 |
| 常用 | 近30天当前范围内日常 Agent 成功读取次数，包含该知识以前有效版本；不是当前正文的采用数 | 读取数降序、更新时间、ID |
| 重要优先 | 用户明确的重要标记；标记代表用户关注，不能提升真假或来源独立性 | 标记优先、更新时间、ID |

迁移时原有条目未标记不等于不重要。标记只由用户操作，不由模型或使用次数自动设置。移动后只使用目的范围内的使用记录，不把原项目次数搬过去；权限变化不泄漏其他项目的使用档案。默认列表排除失效摘要/归档条目，历史仍能查询。

排序游标绑定排序和范围，切换条件不能沿用旧游标。首页“最近新增”和日期活动沿用 P0/P1 的创建/首次索引口径，不因最近更新排序或使用事件改变热力图。

低频、零使用或排名变化不触发删除、覆盖、合并、跨项目移动或全局提升。知识证据仍由版本、来源和用户确认规则决定。

## 验收

U 切片先通过真实读取/检索与明确采用回执、App 浏览/排序，核对各通道分开、旧历史未知、事件重放/冲突、作用域/代次/版本/移动隔离与保留；SQL/交付失败夹具明确标注。迁移前一致性备份与旧表保留；实际窗口、适用 checks/review、完整包、临时 handoff 和提交后继续 I/A/R/G/F。证据放 `build/p3-usage/`，本文不能替代验收。
