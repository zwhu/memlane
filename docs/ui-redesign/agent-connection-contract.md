# Agent 连接与 Codex 处理

2026-11-12。当前范围以[精简版规格](../client-simplification-spec-20261112.md)为准，界面见[当前设计目录](design-catalog.md)。

## 官方集成

采集和召回复用目标 Agent 的 Cognee 官方集成，不新增并行采集器或第二次上下文注入。首条日常链路固定实际使用的 Codex 客户端；CLI 与 Desktop 的状态分别表达，不以一个入口替代另一个。

首版沿官方安装、信任及重载流程完成接入，允许一次性官方安装步骤，不建设通用安装管理平台。只修改明确属于本项目的连接项，保留第三方配置、账号与历史会话。

## 连接与项目

接入是电脑级连接，不以项目、工作目录或第一项任务为前置。项目关联只决定材料归属和检索分组，不能猜测无明确来源的归属。

所有有效接入指向同一个本机官方服务，使用同一官方身份。保留官方连接认证；不提供项目权限、角色或读写白名单。服务地址不可达时不自行创建另一套日常库或启动 fallback。

## 界面状态

设置只显示已安装／待重载／服务可连接等真实连接事实。安装完成不等于产生知识；模型连接、材料接收、官方处理结果和知识产生分别表达。

当前唯一处理入口是 Codex 订阅推理，不显示其他处理方式或配置账本。配置改变通过后台重启生效，具体模型适配见[技术方案](../client-simplification-technical-plan-20261112.md)。

处理会话隔离项目上下文、采集插件、工具和日常历史；认证复用不等于复制全部 Agent 配置。正常编码采集与后台处理的进程各有明确所有者。

## 执行边界

本次只清理设计，未安装插件、切换服务或修改用户配置。后续实施直接使用已确定路线，不安排重复能力探测。真实错误按实际影响修复，历史失败计数继续保留。
