## 选定首页与累计统计

首页保持侧栏＋宽幅总览。内容顺序：记忆动态与整理入口、三项全局累计、全年热力图、最近知识与待确认建议、固定的整理计划摘要。白色内容区、连续浅蓝侧栏、系统字体、紧凑密度、单色按钮。列表与详情另用三栏，普通操作在栏内完成。

| 项目 | 显示与统计口径 |
| --- | --- |
| 累计记忆 | 累计接收的独立原始记录，去重后的数量；重发不累计，对话轮次／实体／关系不计入 |
| 知识 | 当前有效知识，包含整理结果与用户手动新增；原始记录、失效或已归档条目不冒充有效知识 |
| 使用天数 | 从首次使用开始的日历天数，首日为1；不是有新增事件的活跃天数 |
| 每日热力图 | 过去一年每天产生的知识事件；所选日期不改变上方全局累计，后续合并与删除仍能追溯当日事件 |

可选项目初始化导入沿用 [P3-I 契约](../p3-onboarding-contract.md)，导入与日常新增分开，不回填为当天新增热力图；原型 imported 状态的示例数字不能代替该事件分类。

上述口径按这轮设计确定。正式实现需明确持久化所有者、历史事件与当前有效集合、去重和首日字段，复用实际记录，不从示例数字反推字段或预置时间。读取未知显示占位；已有缓存失败则保留上次数据、注明更新时间，不能显示为0。首版不新增实体总数指标，实体／关系浏览仍按原有范围保留。

## 日期、知识与待确认

- 悬停日期显示日期与新增数；点击过滤下方知识，再点取消选择。零新增有独立空态，未来日期不可选。
- 所选日期到详情再通过侧栏回总览时保留日期；“回到最近新增”用于解除日期筛选。
- 最近知识显示标题、摘要、范围／类别、Agent或导入来源与时间，点击定位对应三栏条目。旧条目被合并等变化需准确说明并提供当前知识入口。
- 无知识、只有原始记录、只有导入知识分开表达。日常首页不重复首次配置教程，也不把未整理材料当知识。
- 待确认显示建议类型、项目和待确认数。预览、暂缓、拒绝不改变现有知识；确认后按真实处理结果更新，不把点击当成功。完整审核差异、冲突与来源规则在相应专项设计和工程契约中落实。

## 整理与当前使用方式

“立即整理”触发当前明确范围的任务；运行中同一按钮显示“正在整理”，点击只进入进度，不重复启动。错误进入已有任务的重试；取消本次与停用计划是不同操作。

底部显示下次整理与**具体供应商／模型**，例如 `当前方式：DeepSeek · DeepSeek V4 Pro`。Provider 显示供应商与模型，Agent 显示所选Agent与实际模型，Magpie显示网关与所选模型。来源必须是当前有效配置，不是正在查看的页签、草稿或仅保存的候选。未读到模型时说明未知，不冒称实际命中；已开始任务仍使用启动快照。

没有计划、计划停用、正常下次执行、运行中、自动重试等待、失败与主动停服分别显示真实摘要；正常与异常分别进入计划或进度。明确停止服务保持停止，读状态或回首页不能自动启动。
