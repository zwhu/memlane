## 实际操作与结果

1. 合成知识 c23948d5-acb7-5bff-a9d4-651d2a6fdb6c@1 进入编辑，原正文两行，基线v1。
2. 编辑草稿追加36段中英文和长标识正文。普通1200×820与窄800×620均实际检查；窄窗滚动到 UI_LONG_DRAFT_END_015，返回/保存固定footer仍可见。
3. 正文后按Tab，真实焦点位于返回；Return回同知识，显示未保存草稿，下方仍是已保存v1正文。
4. 切到Synthetic Flow Project再回原项目，选中知识保留；继续编辑后AX完整长文本逐字匹配，仍基于v1。没有据此断言textarea精确滚动位置恢复。
5. 恢复原两行正文后返回，未保存草稿提示消失；从未点击保存。保护五表逐行摘要与015替换前一致：25 memories/39 versions/14 sources/4 common/3 connections。
