## 保留的界面

| 页面 | 作用 |
| --- | --- |
| 总览 | 项目入口、最近知识、真实服务与模型状态 |
| 知识 | 当前项目或通用知识的只读列表、Markdown 正文、复制和来源 |
| 原始记录 | 官方保留的会话、文档与工具记录 |
| 搜索 | 官方搜索、项目分组、真实结果与来源跳转 |
| 图谱 | 官方实体图与代码图组件，项目代码索引开关和手动更新 |
| 设置 | 官方服务位置、Codex 连接与当前模型、必要项目关联、开发入口说明 |

首页保持宽幅；列表与详情采用导航、列表、正文三栏。保留连续浅蓝侧栏、白色内容区、紧凑排版、单色图标，以及普通操作在栏内完成的规则。

默认和最小窗口均为 1200×820，允许放大。首版不设计或实现窄窗口、响应式布局，也不安排相关尺寸适配任务。

知识界面只读。官方插件继续采集，Cognee 继续自动处理；界面如实呈现官方结果。所有有效连接的 Agent 共用官方身份，项目只用于归属和检索分组。

## 设计状态

宽幅首页、均衡三栏、浅蓝侧栏与会话阅读来自既有选定方向。本轮用户授权删除退出范围的功能；这一清理不改变既有视觉方向，也不把旧稿的全部功能重新带入首版。

页面清理、原型展示与 Native 实现分别记录。生产实现仍处于暂停状态；需要实施时按本轮规格直接接线，不重做已经走通的路线验证，不恢复旧的全量验收矩阵。
