# 项目页与统一搜索重设计

2026-11-14，候选 v1。状态：带标注图片与交互说明已完成，待用户审阅；未修改生产代码、未进行 Native 验收。本轮不沿用 CSS 交互稿作为中间实现。

## 用户要求与范围

用户指出项目页不符合预期，要求：移除项目列表搜索与侧栏搜索，全部集中到顶栏；点击顶栏打开类似 Codex 的搜索弹框；整个项目页重新设计；返回、项目设置／搜索按钮、展开后冗长的技术详情均需重新处理。

本提案覆盖项目知识、原始记录（会话／文档）、图谱外层、项目菜单、内容信息和统一搜索。搜索入口调整影响总览、项目、通用知识及设置页的共用导航；这些页面的正文不随之重设计。项目设置仍进入已有设置，不重新设计 PA 规则或改变权限。图谱复用官方画布。

用户明确了搜索集中与弹框方向；三个项目页签、信息浮层和以下尺寸是本提案的设计选择，尚未冒称用户认可。既有“普通操作在栏内、不新增模态”的旧规则，在统一搜索这一明确范围内被本轮要求覆盖；内容信息为锚定工具栏的小浮层，不导航离开阅读页。

## 统一搜索交互

- 顶栏点击或 Cmd+K 打开同一个搜索弹框，背景仅弱遮罩，焦点进入输入框。取消侧栏项、项目列表输入框和裸露“搜索知识”按钮；原搜索页面不再作为一级导航入口。
- 弹框宽760，最小窗口亦保持；最大高 `min(600, 窗口高−160)`，上沿在视口上部留足空间，结果列表内部滚动，输入与底部类型筛选固定。16圆角、轻边线与轻阴影，仅浮层使用阴影。
- 项目页打开默认当前项目；总览与设置默认全部可读范围；通用知识页默认通用知识。范围菜单为“全部／通用知识／具体项目”，具体项目同名时带路径。全部仅包含现有获准范围，不扩大 ACL。图中范围chip即当前项目，不以名称充当身份。
- 底部类型为全部／知识／原始记录。官方命中可证明类型时才分类，不添加不受支持的图谱、文件系统或命令搜索；参考 Codex 的层级与交互，不复制其“新聊天”等不相关功能。
- 初始空词不请求搜索。显示“输入关键词，按 Enter 搜索”；可显示当前会话最近浏览，不读取用户全部 Agent 历史、不新增持久浏览数据库。没有最近浏览时直接保留提示，不伪造推荐结果。
- 输入变化后视为待提交。Enter 提交现有官方检索；不随每次输入自动请求。输入框有未提交更改时 Enter 始终检索；结果就绪且词／范围未改变时，↑↓选择，Enter打开。点击结果直接打开，Esc始终关闭最上层浮层。请求中允许取消，重复Enter不重复发同一请求。
- 修改范围或类型后保留词并显示待检索，Enter提交；清空词返回初始态。可以后续实施复用已有合法结果做本地类型过滤，但不得把一页数据筛选描述成官方完整搜索。
- 结果按知识／原始记录分组，展示真实标题、片段、所属项目与内容类型；只说“已返回N条”，不把top_k命中数当全量总数。片段2行，标题至多2行；缺失项目或来源如实显示未知。
- 返回原上下文时弹框关闭，底层选择与滚动保持。打开结果后提供“返回搜索”；返回恢复词、范围、类型、选中与结果滚动，再Esc恢复搜索前的阅读上下文。跨项目结果按稳定身份打开，不用一个返回字段覆盖嵌套路径。
- 搜索失败保留词与范围，显示可重试错误；已有结果标“上次结果，未刷新”。请求期间不显示假0条，不把旧结果当新命中。明确失效／撤权的结果不可打开，已有正文与复制撤下。
- 焦点限制在弹框中，Tab／Shift+Tab循环；Esc或外点关闭后焦点还给原入口。输入法组合输入期间Enter不抢提交；搜索与信息浮层不同时叠开。

## 内容信息与复制

工具栏信息按钮打开右上锚定浮层，宽450、最大高 `min(560, 窗口高−160)`，内部字段滚动、页脚固定，正文不重排。关闭／切换条目时不残留上一条字段。

保留官方名称、数据组ID、对象ID、原始创建／更新时间及已存在来源字段；缺失省略或明确未知，不能编造。时间显示本地时间和时区；原始时间字符串可在字段复制值中保留。长值折行或省略并提供完整值读取，不丢失原值。每字段右侧一个复制图标，成功行内“已复制”短反馈，失败明确显示；不再使用每项一个独立大按钮。

页脚“复制诊断信息”只复制面板所列字段的完整值和标签，不包含正文、会话内容、凭据或未展示配置。普通内容复制仍复制原官方可见正文；不混入界面标题／按钮文案。复制无有效内容、内容失效或明确无权限时禁用。

## 后续连续验收场景

1. 项目知识读取→切换列表→长标题展开→查看出处→返回知识，列表／正文位置与选择保持。
2. 原始记录全部／会话／文档→分页→工具折叠→返回；核对载入范围、去重及长代码。
3. 顶栏／CmdK→输入→Enter→范围及类型→结果→出处→返回搜索→Esc，搜索与底层状态逐层恢复。
4. 首次加载、成功空、无匹配、局部刷新失败、明确撤权分别核对；迟到响应不得覆盖新项目／新词。
5. 内容信息打开→长字段滚动→单字段复制／诊断复制→关闭，正文不跳动，值和复制范围一致。
6. 项目菜单→项目设置→返回；总览、通用知识与设置的统一搜索入口回归，既有PA行为保留。
7. Native在指定HP外接屏的1200×820、1440×900检查标题、路径、滚动、页脚、焦点、输入法及浮层高度；图片稿不能代替真实截图。

本轮只生成设计资产及文档，没有运行生产验收，不新增或重置既有失败次数。后续沿具体问题触发条件核对历史账本；同一具体问题第四次失败即停止，不以重设计重置计数。原始截图红框是本次设计输入，尚不能据此断言 MyGo 无法实现。
