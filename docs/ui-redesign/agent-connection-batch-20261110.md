## 正式所有者与恢复

- schema24增加 `agent_connection_batch_head` 和 `agent_connection_batches`；迁移前保留schema23备份。存储冻结目标、安装目录、连接ID、代次、尝试次数、阶段、操作重放标识和逐项结果；CAS阻止旧回执覆盖新状态。
- daemon负责逐项安装／验证和取消，IPC启动立即返回持久ID。安装后停在 `awaiting_reload`，用户明确点击「已重载，验证连接」才执行无模型握手；窗口离开不拥有任务寿命。
- 同一启动操作不能更换目标；重放启动、验证和重试不会另建身份或尝试。仅失败／中断／取消项可重试；配置已经安装时优先复用，既有其他连接只登记为保留原连接，不重装、不扩大授权。
- 取消ACK只显示 `cancelling`，直到实际所有者退出再登记终态。已完成安装保留；不会回滚用户配置来伪造整批取消。服务退出等待批次工作结束；重启将活动项标记中断，不自动重装或推理。
- 验证复用正式helper的控制管道guard；服务所有者消失时，guard回收其进程组，不依据陈旧PID向未知进程发信号。本批真实验证证明正常回收，专门的批次所有者SIGKILL窗口仍待补。
- 整库恢复旋转批次身份并退休旧批次；原启动／动作请求及旧worker回执不能在新库生效。SQLite恢复检查同时核对原快照不变。

## Native 与未知回执

初始化和设置复用多选卡片，默认空选，已配置／不支持项不可再次提交，数量仅统计可连接目标。逐项状态、错误和重载提示留在原页；全选、重新检测、重试、验证、取消和继续配置分别保留。底部可换行，普通及980×620组件检查通过。选中不再自动进入旧项目级表单；设置中的显式旧连接管理入口暂时保留，仍需后续按完整C页面收口。

启动／动作请求先保存到客户端 `agent-connection-intent.json`，再发送私有IPC。未知响应保留原操作ID；重开先只读查询原启动或动作是否已记录，不自动另发新任务。用户重试仍复用同一请求。明确的服务拒绝不伪装成未知响应；恢复身份变化会退休本机旧请求。历史批次成功不能遮盖当前连接代次、配置或服务状态变化。
