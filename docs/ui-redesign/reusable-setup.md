## 记忆处理配置

- 三种配置可同时保存，同一时刻仅有一个生效方式。方式选择处直接提示「可配置多种方式，选择一种用于记忆处理」。三个页签保持单行名称，不加「未配置／已配置／当前使用」第二行小字；配置及启用状态集中在下方状态栏，当前有效方式使用上方简洁行表达。当前查看的页签与当前生效方式可以不同。
- 首次引导保存后，后续设置读取同一份供应商、模型、方式与验证状态。已有配置保持，不回到空表单。Provider、Agent 和 Magpie 各自配置可保留，切换不删除其余方式的配置。
- 设置中标明「当前使用」，新候选可以选择并验证。验证成功后点击「保存配置」仅保存该方式；点击「设为当前使用」才改变生效配置。两项操作分开，不因编辑另一种配置而切换。未保存、未验证的新配置不能直接启用；保存和启用均留在本页。
- 「设为当前使用」放在页签下方、当前查看方式的状态栏右侧，紧邻配置状态，默认可见，不藏在底部或滚动列表后。已生效时保留按钮文字并禁用，旁边显示「当前正在使用」；尚未验证或保存时禁用并说明状态。底部只承载保存、取消及初始化完成。
- 点击页签只查看、编辑该方式；各方式的已保存配置与当前草稿分别保留。「取消修改」恢复当前页签的已保存配置。候选验证失败、取消或切换页签，不得改变当前有效方式；不在后台静默回退到其他方式。
- 修改模型、供应商地址或凭据、Agent 登录与版本、Magpie 地址等影响能力的条件后，重新验证。既有成功状态不能直接继承给新配置。
- 后续整理任务使用明确启用的配置；仅保存另一份配置不改变后续任务的执行者。已开始的任务保留启动时的配置快照，切换不隐式取消、重复启动或改写正在运行的任务。初始化可配置多份，选择一种当前使用后继续。
- 供应商设置为可复用独立配置；同一供应商多个模型复用配置。已有密钥不展示原文，更换服务地址需重新提供对应密钥。正式实现沿用安全存储与真实状态，不能复制原型示例凭据。

## Magpie 本机接入纠正

官方仓库 `ed0ab567cba78fae8ea9d9c9a07a7446e315b787` 的 [接入说明](https://github.com/yetone/magpie/blob/ed0ab567cba78fae8ea9d9c9a07a7446e315b787/docs/reference.md#connecting-anything-else) 明确：本机 loopback 调用网关自身端口 `127.0.0.1:3425` 无需密钥。此前 revision 7 强制填写「Magpie 访问凭据」的设计与规则作废。

选择「使用 Magpie」后，自动检测本机网关并读取模型列表。未检测到时显示「打开 Magpie」「重新检测」；网关地址隐藏在「连接设置」，仅供非默认本机端口使用。默认路径不填地址、不填访问凭据，也不读取 Magpie 私有配置、供应商密钥或 Keychain。

当前仅设计本机连接。网络访问或经代理的访问有不同鉴权条件，本轮不增加远程接入模式，不能因本机免密而推广到任意地址。模型请求、返回 ID、结构化输出与 Agent 防循环仍按 [记忆处理契约](memory-processing-design.md) 验证。

## 环境页面复用

- 后续设置进入时直接显示组件及任务当前状态，兼容且完整的组件复用；不重复下载、不重建记忆数据库、不清空知识或记忆处理配置。
- 缺失项使用「准备缺失组件」，就绪时使用「重新检查」。准备、校验、取消、重试与恢复仍原位更新卡片，任务状态由同一后台拥有者管理；离开页面或重开窗口后可继续查看。
- 已有版本不兼容、资源损坏或检测未知时，准确反馈并仅准备所需内容。自动更新兼容性与模型索引代次继续遵守原环境契约，不因复用页面而隐式更换模型或重建索引。
- 设置准备完成后留在「环境与组件」，不再进入选择 Agent、第一项任务，也不重放首次使用引导。
- A01–A04 用户认可的 revision 11 冻结稿保留。本轮只新增设置承载预览，不把新增界面或示例组件状态描述为用户已认可或正式服务验收通过。统一 Cognee/BGE 准备等并行工程规则继续遵循 [环境契约](a-environment.md)。
