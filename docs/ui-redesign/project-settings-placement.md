# 项目设置入口与作用范围

2026-11-10，用户在E候选截图中明确纠正：配置应针对整个项目，项目省略号应放在左侧栏的项目项上。本次确认的是配置对象与入口位置；E完整方案、Native页面、真实项目授权仍需分别确认和验收。

## 入口规则

- 左侧栏每个项目项右端提供「⋯」。当前项目、悬停或键盘聚焦时显示，窄窗口仍可访问。
- 菜单提供「项目设置」以及「补充项目知识」；空项目使用「整理项目」，已有活动任务使用「查看整理进度」。空知识列表保留直接「整理项目」主入口。
- 项目菜单不放在中间知识列表的标题或某一条知识上。知识条目与详情的编辑、历史仍作用于所选知识。
- 展开另一个项目的菜单时保留当前阅读；选择设置后再进入菜单所属项目，不能误用之前选中的项目。
- 菜单关闭保持正文、查询与阅读位置；Escape关闭后焦点回到对应项目的省略号。项目切换保留各项目未保存草稿。

## 配置对象

项目设置对整个仓库对应的项目生效，包括其知识与原始记录；同一仓库的多个worktree共用。右栏明确显示项目名称、仓库位置、该项目的Agent访问状态及默认使用范围，不因选中另一条知识而改变配置对象。

电脑级Agent连接仍在「设置 → Agent连接」。项目权限与电脑级接入分开，新项目不自动授权。Agent范围保存、重载与验证继续复用既有流程；该规则不新增已交付的真实授权能力。
