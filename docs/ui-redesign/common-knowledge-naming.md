# 通用知识：已确认名称与分类

> 2026-11-10 后续导航纠正：侧栏统一去掉“全部记忆”，全局搜索保留跨项目入口。下文早期“暂不移除”的判断已被本次用户指示替代；通用知识命名与内容分类不变。

2026-11-10，用户确认“对，可以叫通用知识，里面可以分个人偏好/通用经验之类的”。本次认可侧栏／页面名称及知识内分类；其余F–O候选和生产能力按独立评审、工程账本记录。

## 名称和用途

| 界面位置 | 当前名称与含义 |
| --- | --- |
| 侧栏入口、页面标题 | 通用知识：供不同项目参考的知识 |
| 知识内分类 | 个人偏好：用户明确保存的表达、工作习惯或默认选择 |
| 知识内分类 | 通用经验：跨项目参考的方法和结论，保留适用条件 |
| 项目知识操作 | 原文复制到通用知识、AI提炼为通用经验 |
| 来源、整理结果、Agent访问范围 | 统一上述名称，个人偏好／通用经验可分别授权 |

原“全局记忆”在当前界面统一显示为“通用知识”；旧“全局经验”当前显示为“通用经验”。历史契约和验收里的全局scope描述仍按原含义解释，不能用旧产品结构恢复旧界面名称。

通用知识不是所有项目知识的合集。项目知识、通用知识的适用范围分别保留；项目明确约定优先于通用内容。保存为通用知识不自动扩大来源项目访问权限，也不会删除源知识。内部`global`、`preference`、`experience`标识与现有来源版本、授权和存储契约不因界面改名而迁移。

## 分类与页面承载

知识列表直接提供“个人偏好／通用经验”分类按钮，初次可同时浏览两类，点击按分类筛选，再次点击清除该分类。详情保留匹配条目，必要时切到同类结果；无匹配明确提示，不展示其他项目内容。分类不新增“全部”内容页签，项目仍使用知识／原始记录。

页面沿既有紧凑三栏、侧栏和原型样式；进入通用知识时选中对应侧栏入口。复制／提炼先预览，通用经验保存需确认适用条件；原项目知识与历史保持。此处只确认设计要求，真实保存、分类、授权和实际窗口仍须工程证据。

侧栏“全部记忆”已按后续纠正移除，跨项目浏览由全局搜索承接。原命名确认不变，导航以后续纠正为准。
