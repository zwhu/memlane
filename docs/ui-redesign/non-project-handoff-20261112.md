## 总览

总览采用侧栏加宽幅内容，按 2026-11-13 最新确认恢复之前的结构：热力图上方展示使用天数、知识总数和原始记录总数，下方保留每天新增知识热力图、近期动态、最近知识、项目入口和轻量连接状态。首日固定为首次初始化完成日。详细规则见[总览规格](../overview-spec-20261113.md)，当前原型和截图待更新。点击知识进入对应项目的阅读视图，点击连接状态进入设置。

没有知识时说明当前为空，并提供项目或连接入口；读取失败时保留上次有效内容和错误说明，不能误称空库。服务不可用与模型不可用分别呈现，模型错误不抹去已有知识。

首页仍删除待确认、计划和永久活动库。本次恢复的统计与近期动态复用官方数据，只持久保存首日等必要客户端状态。官方活动次数不能替代每日新增知识；数量、全量分页、来源去重和状态准确性分别验收。

## 通用知识与搜索

通用知识仍称“通用知识”，个人偏好与通用经验按官方实际类别呈现，复用只读三栏。不存在对应类别时不为示例填充条目，不自动提升项目内容。

全局搜索保留跨项目分组；项目内搜索默认当前项目。搜索直接使用官方查询，结果带真实身份和出处，不用已加载的一页列表代替完整搜索。打开结果后可返回搜索词、结果和选中位置。

搜索中、无匹配、失败和内容失效分开。官方返回混合类型时标明知识或原始材料，不额外建立分类索引。

## 设置

设置保留三组简洁内容，普通操作在当前页完成：

| 内容 | 字段与状态 | 操作范围 |
| --- | --- | --- |
| 官方服务 | 当前本机服务地址、连接结果、开发入口说明 | 查看状态与启动器使用说明 |
| Codex | 官方插件连接、是否需重载、当前处理模型、认证或模型错误 | 沿官方安装与登录流程处理，不另做插件平台 |
| 项目关联 | 显示名、仓库路径、官方知识数据组及可选代码数据组 | 维护必要配置映射，不管理访问权限 |

处理方式只有 Codex，复用其订阅登录。当前配置变更通过重新启动后台生效；不增加方式页签、配置历史或运行中切换。向量模型由官方运行配置管理，不把 Codex 登录描述为向量能力。

首次连接允许沿官方步骤完成，设置不再承载安装器、组件管理中心和发布维护流程。关窗后台保持、电脑重启后手动启动的说明保持一致。

## 共同布局与状态

默认和最小窗口均为 1200×820，允许放大。首页与设置宽幅，知识和搜索使用三栏。侧栏 196px，列表约 300px，阅读栏使用剩余空间；首版不设计或实现窄窗口及响应式布局。具体阅读参数见[阅读交接](conversation-reading-handoff-20261112.md)。

标题与必要操作保持可见，长内容局部滚动。读取失败保留选择与正文，切换项目不串数据。服务状态轮询不重建整个页面，也不触发后台自动启停。

当前稿删除手动新增编辑、内容历史与恢复、审核、定期计划、权限、多模型、备份恢复、索引维护和自动更新页面；其独立状态与跳转一并删除。生产代码、真实数据与已有工程证据不属于本次文档清理。
