# Agent 连接与项目知识：已确认的入口和任务方式

2026-11-09。Agent 连接位于设置，项目知识建立属于日常项目操作。用户最新明确：“这里没必要导入相关知识，直接给个按钮，让用户自己选择使用自己的Agent去分析知识存入”。本轮按该要求移除 App 管理的文件选择、知识导入和仓库分析向导，只提供项目指令，由用户自行使用 Agent 分析与保存。

## 固定入口

| 功能 | 入口与职责 |
| --- | --- |
| 环境与组件 | 设置 → 环境与组件，复用 A 已认可内容和组件任务 |
| Agent 连接 | 设置 → Agent 连接，三栏管理发现、连接、重载、验证、断开、访问范围和使用记录 |
| 记忆处理 | 设置 → 记忆处理，复用 A 的三份配置、独立保存与一个当前使用 |
| 建立项目知识 | 项目页的「用 Agent 建立项目知识」按钮，复制当前项目的分析与保存指令 |
| Agent 详情快捷操作 | 「前往项目知识」，进入项目；执行者由用户自行选择，不在 App 再设置一次分析 Agent |

主侧栏不保留一级 Agent，设置共享环境与组件／Agent 连接／记忆处理。项目页不显示文件列表、大小上限、分析目标表单或 App 管理的导入进度。也不要求把仓库拆成16个文件逐次导入。

## 按钮的实际行为

1. 带入当前项目名称和上下文，复制分析指令；不扫描文件、不启动模型，也不创建导入批次。
2. 用户自行选择自己的 Agent，粘贴指令并执行。Agent 使用其自身模型、工具和上下文按需分析仓库，通过已连接的 Memlane 记忆能力正常保存到该项目。
3. App 只显示复制成功／失败。保存与索引事实来自真实记忆回执，不能把复制或分析文字当成知识已经存入。复制失败可选择指令手动复制，不丢当前项目与知识阅读位置。

指令提醒 Agent 核对实际仓库与已授权项目，无法唯一匹配时先确认；记录真实文件出处与版本。合并、覆盖、删除、跨项目移动仍需明确确认。用户自选 Agent 不等于绕过服务端范围与连接代次校验；按钮不扩大任何记忆权限。

知识使用正常 Agent 保存与来源规则，不套用旧 App 文件导入的 imported 批次语义。旧 P3-I 的1–16文件／128KiB受控导入是对应版本的工程能力与证据，本次不删除其生产代码，也不将其限制当成新按钮的仓库规模上限。
