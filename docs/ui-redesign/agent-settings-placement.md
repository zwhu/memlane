# Agent 设置与项目知识库初始化

2026-11-09。Agent 连接位于设置，项目知识库初始化属于日常项目操作。用户最新明确：“这里还应该是初始化知识库的概念，让用户自己点一下，然后用绑定的Agent去分析，所以你可以提供这个按钮，但是需要一个特别酷炫的交互来承载”。入口与这一产品概念已确认；C revision 4 的具体动效和承载仍是待评审原型。

## 入口与职责

| 功能 | 入口与职责 |
| --- | --- |
| 环境与组件 | 设置 → 环境与组件，复用 A 已认可内容和组件任务 |
| Agent 连接 | 设置 → Agent 连接，三栏管理发现、连接、重载、验证、断开、访问范围和使用记录 |
| 记忆处理 | 设置 → 记忆处理，复用 A 的三份配置、独立保存与一个当前使用 |
| 初始化项目知识库 | 项目页「初始化知识库」，在右栏承载绑定 Agent、主动启动、分析和保存状态 |
| Agent 详情快捷操作 | 「前往项目知识」，进入项目；沿用项目绑定，不把设置页选中项直接当成初始化执行者 |

主侧栏不保留一级 Agent，设置共享环境与组件／Agent 连接／记忆处理。A 初始配置仍只有准备环境、连接 Agent、配置记忆处理三步；项目知识库初始化在日常项目页独立触发，不重新加入首次配置。

项目页不显示文件选择、大小上限、阅读范围表单或导入向导。由用户自己的编码 Agent 按需理解仓库，不要求把几百个文件拆成16个文件逐次导入。

## 主动启动与绑定

1. 项目页入口打开右栏，保留中间知识列表和原选中项，不自动运行。右栏显示当前项目的绑定 Agent；用户点击「使用 Codex 初始化」等明确主操作后开始。
2. 绑定必须是已连接、适配支持且获准访问当前项目的 Agent。没有绑定时先由用户选择；仅发现另一款可用工具不会自动绑定或替换原绑定。连接本身仍是电脑级配置，项目授权另行确认。
3. 本次任务固定项目、绑定 Agent 和尝试标识。运行中不能重复启动或更换执行者，不默默切换记忆处理 Provider、模型或网关。
4. Agent 复用自身模型、工具与仓库上下文，形成带文件出处的项目知识，通过正常 Memlane 保存规则存入当前项目。它不沿用旧 App 文件导入的批次材料语义。
5. 原有有效知识保留。AI 提出的合并、覆盖、删除和跨项目移动仍需用户确认，初始化动作不扩大读写权限。

## 右栏动效与状态

沿用 A/B 的浅色、单色与方块语言。本稿采用仓库卡片、立体小方块、知识卡片和记忆书，右栏内完成操作：

| 状态 | 画面与反馈 |
| --- | --- |
| 待开始 | 小方块轻微悬浮，知识卡片为淡色示意；显示绑定 Agent 和主动启动按钮 |
| 连接 Agent | 方块逐个向中心归整，表达本次分析会话准备 |
| 分析仓库 | 方块成阵列轻微起伏，知识主题逐步显现 |
| 保存知识 | 方块汇入项目约定、系统架构和关键模块卡片 |
| 建立索引 | 知识卡片显示扫光，明确知识已保存但仍在准备检索 |
| 完成 | 卡片收束，记忆书展开并出现完成标记；提供查看项目知识 |
| 中断／停止 | 方块静止，提供明确原因、重新开始或返回知识；不播放完成动画 |

指针在舞台内移动时有轻微视差，启动按钮有按压反馈。系统减少动态效果时关闭漂浮、视差、扫光和过渡，以文字与静态状态表达进度。

动画不能推进真实任务，也不能用时长推算完成或知识数量。保存成功和可检索以各自真实回执反馈。收起右栏或选择已有知识不等于取消，重新打开应回到同一任务。停止先等待取消结果，停止后不接纳该尝试的迟到状态；重试产生新尝试，旧回执不能覆盖新任务。

失败时可提供「复制到绑定 Agent 中执行」备用操作；复制失败可以手动选择指令。复制只表示取得指令，不表示已启动、保存或索引成功。该备用操作不替代正常启动入口。
