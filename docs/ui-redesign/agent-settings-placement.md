## 固定入口

| 功能 | 主入口 | 承载 |
| --- | --- | --- |
| 环境与组件 | 设置 → 环境与组件 | 复用 A 已认可环境内容和后台组件任务 |
| Agent 连接 | 设置 → Agent 连接 | 现有导航—安装列表—详情三栏；连接、重载、验证、断开、访问范围和使用记录 |

## 项目上下文

- 从项目页进入时带入准确项目，文件授权与提交属于该项目；不能因为临近另一个项目或上次使用 Agent 而切换。
- 从 Agent 快捷入口进入时带入所选工具，再选择明确项目；实际批次仍绑定稳定项目／Agent连接／代次／材料版本。
- 导入结束或取消后回到对应项目；从项目列表进入时恢复其列表位置。查看连接属于切换到设置的明确操作，不能丢失已登记批次或把它标成完成。
- 入口调整不修改导入契约：复制不是提交；保存与索引分开；索引失败只重试索引；取消先于提交则拒绝迟到提交，提交先于取消则保留已保存事实。
