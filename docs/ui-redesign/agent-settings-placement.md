# Agent 设置与项目知识整理

2026-11-09。Agent 连接位于设置；项目知识建立由用户主动启动绑定 Agent 整理并保存。用户进一步指出“初始化”难理解，要求明确 Token 消耗、可选择同时整理过去的 session、仅知识为空时出现建立入口，并纠正页内知识／记忆混用。

当前 C revision 7 已认可，统一使用「整理项目」「项目知识整理」「查看整理进度」和「停止整理」。方块动效、空态、历史会话选择和 Token 提示按固定原型归档；MyGo 实现参数与后续动效统一规则见 [动效实施与复用](motion-implementation.md)，实施入口见 [C 交接](c-agent-handoff.md)。

## 入口与可见条件

| 功能 | 入口与职责 |
| --- | --- |
| 环境与组件 | 设置 → 环境与组件，复用 A 已认可内容和组件任务 |
| Agent 连接 | 设置 → Agent 连接，管理发现、连接、重载、验证、断开、访问范围和使用记录 |
| 记忆处理 | 设置 → 记忆处理，复用三份配置、独立保存与一个当前使用 |
| 建立第一份项目知识 | 项目知识列表的空态卡片「整理项目」，右栏承载绑定、范围、Token提示和主动启动 |
| 已有知识 | 隐藏空态大按钮，项目「⋯」菜单保留「补充项目知识」，复用原整理面板 |
| 已启动任务 | 通过「查看整理进度／查看进度」回到原任务，不创建重复任务；已有知识出现后也可恢复未完成任务 |
| Agent 详情快捷操作 | 「前往项目知识」进入项目，沿用项目绑定，不把设置选中项直接当成执行者 |

「只有空知识列表出现主启动按钮」依据真实项目知识数据，而非全局总数、当前筛选零结果、读取中或读取失败。已有数据读取失败时保留旧内容并显示错误，不能当空库引导用户重复整理。

空态中，中间栏展示轻量方块／知识卡片图形、说明、整理按钮及 Token 提示；右栏展示知识成形预览。悬停／键盘聚焦整理入口时方块预览归整，不启动 Agent。点击后在右栏选择与启动。普通操作仍在栏内完成。

项目整理可以一直跳过，不阻塞已连接Agent的正常提交与日常记忆；只有实际提交的内容才进入记忆，原始材料不会因新会话结束而必然成为知识。后续想回补仓库或历史会话，可从项目「⋯」菜单选择「补充项目知识」，明确范围和Token消耗后启动，已有有效知识保留。

A 首次配置仍只有准备环境、连接 Agent、配置记忆处理三步。项目知识整理不重新加入首次配置，不显示文件选择、大小上限、阅读范围表单或导入向导；由用户自己的编码 Agent 按需整理仓库，不要求将几百个文件拆成16个文件逐次导入。

| 所在位置 | 当前用词 |
| --- | --- |
| 项目内容页签 | 知识／原始记录，默认知识，分别计数 |
| 知识条目详情 | 知识详情 |
| 整理任务右栏 | 项目知识整理 |
| 主动启动 | 使用 Codex 整理，按实际绑定工具显示名称 |
| 任务状态 | 项目整理中 |
| 明确终止 | 停止整理 |
| 离开任务承载 | 查看知识：回到项目知识阅读，保留当前任务；不表示暂停或停止 |
| 失败后的范围调整 | 调整整理范围，先回到配置，再明确重新整理 |

产品、服务和已有导航中的「记忆」仍表达整体记忆能力；知识页签展示可复用结论，栏标题及同类操作统一使用「知识」；原始记录页签保留会话／工具原文。概念和产生时机见 [内容分层](content-model.md)。原始会话使用「原始记录／历史会话」，不冒充已经形成的知识。知识原文本身的标题和内容保持原文，不为术语统一改写用户数据。

删除原「收起」的模糊用词。运行时只保留一处知识阅读入口；底部负责停止或重试，避免上下重复的查看操作。完成后提供查看项目知识，不保留对已有知识再次启动初始整理的常驻大按钮；后续补充使用项目二级菜单。

## 绑定、Token 与历史会话

1. 打开空态入口不会自动运行。显示当前项目绑定的 Agent，用户点击明确主按钮才开始；仅选择历史会话也不会触发模型请求。
2. 绑定必须已连接、适配支持且获准访问当前项目。无绑定时先明确选择；发现其他可用工具不自动绑定或替换。电脑级连接与项目授权分开。
3. 「同时整理历史会话」默认关闭。开启只选择当前绑定 Agent、当前项目可可靠归属且已授权的历史会话，提炼需求、决策和排查经验；不扫描其他 Agent 或其他项目的聊天。
4. 切换绑定 Agent 清除历史会话选择，用户对新执行者重新选择。运行时固定项目、Agent、历史会话选择和尝试标识，禁止重复启动或中途改变范围。
5. 启动按钮旁明确提示「会消耗 Token」，说明使用绑定 Agent 当前模型，用量随整理内容变化；勾选历史会话后额外提示「历史会话会增加用量」。不编造 Token、费用、时长或会话数量，也不将 Token 消耗等同于一定产生额外付费。
6. Agent 不支持历史读取时禁用该选项并说明原因。实际执行读取失败、无法确认项目归属或来源不可用时，应明确报告未完成范围，不能默默跳过后显示全部成功。
7. Agent 复用自己的模型、工具与仓库上下文，通过正常 Memlane 保存规则提交带出处的知识；不默默切换记忆处理 Provider、模型或网关，不沿用旧文件导入批次语义。
8. 已有有效知识保留。AI 合并、覆盖、删除、跨项目移动仍需用户确认；勾选历史会话不扩大记忆权限或授权范围。

历史会话是来源。保留会话标识、消息时间及可核对的原始出处，不能把本次整理时间冒充原会话时间或补造旧活动；从历史材料新提炼的独立知识按普通新增规则统计。重复整理不重复保存同一知识，也不自动覆盖已有内容。

## 右栏动效与中断

沿用浅色、单色与方块语言：待开始漂浮 → 启动 Agent时逐块归整 → 整理项目／会话时轻微起伏 → 保存时汇入知识卡片 → 索引时扫光 → 完成时记忆书展开。

历史会话选择不改变舞台语言；运行时保留范围选择的只读状态，阶段文字体现仓库与历史会话。失败、取消中和已停止时方块静止，不播放成功动画。系统减少动态效果使用静态目标和文字，具体参数按 [MyGo 动效交接](motion-implementation.md)。

动画不能推进真实任务、按时长宣告成功或生成知识数。保存成功与可检索依据各自真实回执。查看知识或切换阅读条目不取消任务，重新打开恢复同一尝试。停止等待取消结果，旧尝试输出不得覆盖取消或新的重试。

失败时可复制到绑定 Agent 执行备用指令，指令必须携带相同项目、绑定工具和历史会话选择；复制失败支持手动选择。复制不代表真实启动、保存或索引成功。
