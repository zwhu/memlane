# Memlane 重设计场景清单

2026-11-09。本清单依据当前首版产品规则、最新产品确认、现有页面入口和本轮用户反馈整理。用于逐项讨论设计，覆盖已实现及已确认待完成的流程，不是实现或验收完成报告。

当前 A 初始配置、批量连接、记忆处理与设置复用的 revision 13 已由用户确认归档，以 [A 实施交接](a-setup-handoff.md) 为准。B 日常首页 revision 5 同样已认可归档，见 [B 交接](b-home-handoff.md)；C 正在设计，未认可。其余分组仍按各自确认状态推进，场景枚举不代表设计或实现已完成。

## 已确认的设计边界

- 首次引导在首次设置过程中完成，日常首页不重复出现“初次使用／开始使用／先连接 Agent”。中断后继续设置与日常故障修复是独立场景。
- 首次设置顺序：准备环境 → 连接 Agent → 配置记忆处理 → 完成配置进入首页。用户最新明确：第一项任务与记忆结果移出初始化，项目与材料范围在日常使用中处理。
- “首次设置”与可选的“导入已有项目知识”分开描述；后者不会每次启动都发生。
- 首页采用宽幅总览；列表与详情采用导航—列表—详情三栏；普通新增、编辑、审核在栏内完成。
- 原始记录阅读可独立承载；具体采用侧页、完整页面或弹框，仍需此次设计讨论确定。
- 保留记忆、实体、关系图；首版隐藏代码图谱入口。其他主机的远程管理继续留在 Roadmap。
- AI 合并、覆盖、删除、跨项目移动在确认前不改变有效知识；恢复旧知识产生新版本。
- 清单只枚举用户能感知的任务和状态，后台工程实现细节不单独变成产品页面。

| C05 | 连接异常或重新验证 | 恢复实际读写能力 | 服务不可用、认证失败、权限不足、模型不支持、超时；重试、取消 |

| C08 | 复制导入 prompt 后等待 | 到自己的 Agent 执行导入任务 | 已复制但未提交、正在执行、部分接收、完成、失败、重复提交 |
| C09 | 查看或取消导入批次 | 查看实际回执与具体出处 | 导入项、保存／索引状态；取消、过期、来源变更、迟到提交被拒绝 |

## D 日常记忆进入与复用

| 编号 | 场景／入口 | 用户要完成的事 | 要设计的状态和分支 |
| --- | --- | --- | --- |
| D01 | Agent 产生新记录后回 App | 知道哪些内容进入了记忆库 | Agent 未提交、原始记录已接收、知识已保存；默认采集时机仍待确定 |
| D02 | 新知识等待检索可用 | 判断保存与索引进度 | 已保存、排队、索引中、可检索、索引失败；重试索引 |

| D05 | 后续任务或另一 Agent 复用 | 查看记忆有没有被再次获取 | 检索返回、成功读取、明确报告采用分别呈现；无结果与服务失败区分 |

| N16 | 再次启动 App | 回到日常界面与真实状态 | 正常启动、服务主动停止、服务异常、未完成首次设置；不重复已完成的引导 |
