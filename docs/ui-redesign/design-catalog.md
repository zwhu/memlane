## 今日首页

[当前首页](http://127.0.0.1:18764/b-home-overview.html)按用户指定顺序：数字 → 每日新增知识热力图 → 最近动态 → 项目中的知识。状态包括正常、新增、近期安静、只有原始记录、活动读取失败及繁忙。繁忙时首页显示4条动态、3项待确认及总数；完整列表支持项目／类型筛选、每页8项。项目内独立动态入口本轮暂不增加。

B当前知识详情与待确认预览是首页承接夹具；完整正文／编辑／审核按F/G/H/K专项。本轮已删除B内设置／计划／新增／整理／添加项目的重复简化承接，接到A/E/H/J/M完整稿。不同示例条目的ID不能冒用为同一条知识。

当前三项数字为知识总量／原始记录／待确认，与旧B已认可稿的累计记忆／知识／使用天数存在差异。用户确认了布局方向，本轮将指标差异明确留档，不能据示例数值改写已确认统计口径。活动事实、使用记录和待确认队列分别管理：90天滚动保留只来自[使用记录契约](../p3-usage-contract.md)，不延伸为删除所有活动／知识／审核历史。
