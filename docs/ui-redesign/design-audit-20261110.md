## 仍需收拢，不能伪装完成

1. **B与完整详情的示例身份**：B的知识／原文／建议详情仍使用自己的一组条目。需要后续把B事件、F/G阅读及K审核统一到相同知识ID、来源版本和任务ID，并验证返回日期／筛选／滚动。此轮保留B完整列表交互与G/K完整能力，不将不同标题硬连成同一知识。
2. **B指标口径**：当前是知识总量／原始记录／待确认，旧已认可口径为累计记忆／知识／使用天数。布局方向按今日要求更新，数值字段不从示例反推。实施前按该差异定最终口径。
3. **已纠正的导航回退**：用户指出整理稿仍有“全部记忆”，确认此前应移除。现已移除当前B/C/D及F–O侧栏入口，并纠正命名交接／AGENTS中的旧判断；跨项目范围和全局搜索保留。旧固定提交与历史截图只用于追溯，不作为恢复该入口的依据。
4. **项目动态**：依用户“暂时不用补”，本轮不增加项目内独立动态入口。D仍是已有生命周期专项评审页面，不宣称已接入每个项目日常导航。
5. **历史保留边界**：使用记录90天滚动保留不是所有动态的统一生命周期；待确认、知识版本、操作审计不得据此自动清除。完整动态归档策略不在本轮追加设计。
