# 知识与原始记录

2026-11-12。当前范围以精简版规格为准。

## 官方数据为主

Cognee 是内容唯一数据源。Memlane 通过官方接口阅读知识、文档、会话、片段、索引结果与图，不保存第二份正文或索引。客户端只保存必要配置、项目到 dataset 的关联与界面偏好。

## 内容类型

- 记忆是整体名称，不是与知识、原始记录并列的第三种类型。
- 知识是官方实际保存、供后续复用的明确结论。
- 原始记录是官方实际保留的材料，可以是会话问答、工具记录、文档或片段。
- 会话缓存不自动等于长期保存；只显示实际取得的内容范围。

原始记录被检索或处理后仍是原始记录。只有官方实际生成知识，知识列表才增加条目；无结果、去重或未提炼时如实显示。

## 阅读与来源

项目默认知识页签，可切换原始记录。列表和详情使用同一官方 ID 与类型，来源沿官方关联跳转，不拼造完整对话或逐轮关联。只取得尾部或部分材料时显示“已载入”，不冒充全部。

来源页返回保留查询、选择、滚动和工具展开状态。首次加载、空结果和读取失败分别显示。刷新不卸载有效正文；对象身份替换或来源确实失效时撤下过时内容。

## 本阶段行为

知识界面只读，保留浏览、搜索、复制与来源跳转。官方插件写入材料、官方生成或更新知识继续工作。

通用记忆沿用“个人偏好／通用经验”分类，项目明确约定优先；不自动将项目记忆提升为通用记忆。受管 Agent 按类型与独立 profile 各自持有独立官方子主体与 `X-Api-Key`，并按项目级 PA ACL（`none` / `read` / `maintain`，其中 `maintain` 含 `read/write/delete`、不授 `share`）控制读写权限；电脑级连接准备仅建立身份与凭据，不自动授予任何项目、通用记忆或受保护数据集（如 `ml-user-profiles`）的访问权（详见[电脑级接入契约](../architecture/agent-connection-contract.md)与 [CONTEXT.md](../../CONTEXT.md)）。

旧 Memlane 正文、历史和独立索引直接删除，不迁移。Cognee 已有数据、Agent 自身会话和必要配置保留；执行边界见规格，本次设计清理没有操作运行数据。
