## 每切片验收层

1. 正式契约：输入范围、来源版本、决定、幂等回执、事务、恢复与索引；迁移前备份，并用临时旧库证明保留。
2. 主流程：真实 App 用户操作 → 真实 Agent → 服务事务 → 真实 Rust 检索。合成正文置于新临时根；正常和活动取消使用真实模型。
3. 故障：明确标为 SQL/协议/进程/网络/磁盘/UI 夹具，核对取消、竞争、过期、重启、迟到与回滚；夹具不代替正常流程。
4. 检查：`sh scripts/go.sh test ./...`、`vet ./...`、受影响 race/服务集成。UI/包变化构建完整 helper/LaunchAgent 包，实际打开设计图并对照系统窗口截图。
5. 交付：文档仅勾真实通过项，检查链接；阶段临时 handoff 核对存在；仅提交本目标相关代码文档，不包含 build、秘密、真实库、用户配置或 handoff。

## 外部条件与解除方式

只读 `security find-identity -v -p codesigning` 返回 0 个有效身份。当前 mygo.json 无正式更新源，P0/P2 的受控源与 ad-hoc 包只能用于本机验收。当前机器不是干净 macOS 15+ 验收环境。用户需确定实际发布渠道、提供可用的 Developer ID/公证配置和可验收设备；仅查询可用性，不读取/输出凭据。授权范围内先完成可审查包和本机验证，再进行需要渠道授权的正式发布。

这些条件缺失时 F3 保持未通过，继续其他工作，不能标记整体完成。Intel、Windows/Linux、其他主机、多设备同步、VoiceOver 增强继续见 Roadmap，不进入本矩阵。

## 工程收口

正式页面继续叫“整理记录”，未定“梦境”名称不从原型导入。摘要以有出处知识表达，不赋予同源独立证明；排序/事件保留与计划预算在对应契约切片记录决策和依据。只随实际功能添加表；不建立空平台。通用 Cognee 模型桥只有实际接口收益与副作用证明需要时才引入。
