## 最高优先级

用户：“接下来我觉得最重要的事情是先链接一个真实的 agent，测试 agent 产生的记忆是怎么被记录的。”

验证路径：接通一个真实 Agent → 正常对话或执行任务 → 按 Cognee Integrations 的实际机制采集／提交和同步记忆 → Memlane 中查看实际记录、来源与范围 → 新会话验证召回。

重点观察记忆在什么时候产生、保存哪些内容、归到哪里，以及用户怎样知道已经保存成功。验证期间只使用本轮明确的合成材料和隔离数据，不读取或导入用户历史聊天。

## 接入约束

用户：“Agent 提交记忆是按照 cognee 的 integrations 的方式。”

按官方对应 Agent 的插件／hooks／接入流程验证真实行为。官方流程可能包含原始会话记忆、同步与提炼，需逐项观察并与 Memlane 的知识、出处、版本及确认规则衔接。现有 Memlane MCP 的单次保存测试不代表本次官方集成路径通过。

先验证实际机制，再讨论日常自动记忆策略。之前 `product-memory-flow.md` 提出的三种默认保存方式尚未得到选择，不将它们作为用户确认。
