# 总览统计与每日动态规格

日期：2026-11-13。状态：待实施。产品入口：[产品方案](overview-product-plan-20261113.md)；实现入口：[技术方案](overview-technical-plan-20261113.md)。本文件覆盖旧精简稿中总览不展示统计、热力图和动态的对应表述，其余精简范围保持。

## 数据与显示契约

| 编号 | 要求 | 验收标准 |
| --- | --- | --- |
| O01 | 首日持久化 | 首次初始化完成写入一次；保存 UTC 完成时间及当日本地日期；日期为计数基准，之后不重算首日 |
| O02 | 使用天数 | `max(1, 本地今天日期 − 首日日期 + 1)`，使用日历日期差；当天为 1，跨日增长；初始化未完成时不伪造天数 |
| O03 | 知识总数 | 对全局纳入范围的官方有效知识按官方身份去重，遍历完整分页后显示；不计材料、实体、片段、代码节点 |
| O04 | 原始记录总数 | 会话与原始文档统一去重；同一会话的落盘材料、提炼结果不能再算新的原始会话；独立文档按独立官方身份计数 |
| O05 | 热力图 | 展示含今天在内最近 365 个本地日期，以有效知识创建时间按天聚合；更新正文、处理重试不作为新增 |
| O06 | 日期回顾 | 点击有内容日期后，下方知识区显示该日结果并保留分页；顶部总数保持全局，清除选择恢复最近知识 |
| O07 | 近期动态 | 最近 20 个归并后的官方事件，时间倒序；有更多时在模块内加载；一轮处理的多条状态合并为一个最新状态事件 |
| O08 | 状态准确 | 处理中、完成、失败分别展示；后台已受理／启动不能当完成；失败不算知识增长 |
| O09 | 阅读连续性 | 刷新不清空有效内容、选择和滚动；迟到响应不覆盖新日期或新数据范围 |
| O10 | 状态独立 | 一个模块失败不使其他模块归零或撤下；无数据与读取失败分开，重试不触发写入或推理 |

界面统计名称固定为「已使用 X 天」「知识 X 条」「原始记录 X 条」，不使用“累计生成”暗示已删除历史也被保留。首日算法不进入普通用户流程。

全局范围为当前已关联项目与通用知识的数据组并集，按官方服务／数据空间身份和 dataset ID 去重。代码专用组与未纳入范围的测试／系统组不计。无 dataset 的全局活动只在确认属于当前官方身份后展示，不猜测所属项目。

## 首日与异常

初始化完成指必要配置已保存，官方内容服务已通过带认证只读检查，Codex 处理端点健康检查通过，可以进入总览；无需等待首条知识或额外发起模型调用。现有 dev 流程采用同一完成判据，不新增初始化向导。

完成事件与首日保存为同一幂等提交：已有记录直接复用，缺失才创建；保存失败保留错误供重试，不宣称首日已记录。没有该字段的既有安装，在更新后首次满足上述判据时补记当天，不倒推原始安装日。初始化中断或失败不写入。

首日保存在应用持久状态中，独立于单次进程 owner、项目和模型配置。普通重启、升级、重配与重复完成均不重置。系统日期早于首日时最小显示 1 天，不覆写记录；时区变化不重新换算已保存首日，只使用当前本地今天计算。

## 数量与历史边界

总数必须来自全部分页，不能把当前页面条数或图节点数当总数。官方删除、替换或归属移出范围后允许总量下降；热力图相应反映当前保留知识，不补建终身统计账本。

没有创建时间的知识仍计入有效知识总数，但不得以更新时间补造新增日期；热力图显示简短数据不完整提示。官方时间无偏移时，只有核实其 UTC 语义后才能按 UTC 转本地，不能直接当本地时间。

原始记录来源映射无法可靠去重时，记录不能精确统计的技术缺口，界面保留上次完整结果或显示不可用，不将两类列表直接相加后宣称准确总量。

## 连续验收场景

1. 初始化中断 → 重试完成 → 首日当天显示 1 → 关窗、重开、升级、改模型、重复完成 → 首日不变；次日本地日期变化后显示 2。
2. 空内容 → 官方接收一条会话及对应材料 → 原始记录增加 1 → 提炼生成知识 → 知识与对应日期增加，材料不混入知识。
3. 超过一页知识／原始记录，多个项目引用同一组且包含通用知识 → 总量去重正确；排除代码专用组；列表分页与总量一致。
4. 同一知识更新、同一处理多状态、重试与失败 → 不重复新增；后台启动不显示完成；近期动态按运行合并。
5. 选择日期 → 打开知识／出处 → 返回 → 日期、选择、滚动保持；刷新或跨日不清空已有阅读。
6. 单模块超时、鉴权失败、缺时间、无来源关联 → 不归零、不假成功、不伪造日期和跳转；恢复后重新发布完整结果。
7. 官方删除／替换知识、会话到期或项目移出范围 → 当前总量和热力图按真实保留内容更新，不保留幽灵条目。

后续源码定向检查、真实官方数据对照与实际 Native 1200×820 窗口分别留证。夹具不能证明真实全量、真实关联或窗口还原。本轮文档不登记为产品验收通过；失败沿用仓库同问题计数与第 4 次停止规则。
