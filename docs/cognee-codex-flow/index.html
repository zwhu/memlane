存下 session，不等于提炼完成

原始会话条目、会话上下文候选、学习文档和图谱／向量是不同产物。早期反馈或失败上下文也不能当成最终知识。

“同步”在两处含义不同

插件的同步提交 improve，促使 Cognee 处理已有会话。Memlane 的同步读取官方材料，并分层导入自己的业务库。
