# 总览统计与每日动态产品方案

日期：2026-11-13。状态：用户已确认方向，本文为待实施方案；不表示代码、原型或 Native 界面已完成。配套：[规格](overview-spec-20261113.md)、[技术方案](overview-technical-plan-20261113.md)。

## 目标与决定

用户希望总览恢复之前的设计：知道使用了多久、积累了多少知识和原始记录，并通过热力图和近期动态回顾每日变化。

本次明确覆盖精简设计中“暂不展示热力图与动态”的决定。复用旧首页的宽幅布局和三项统计结构，不恢复审核、计划、权限或其他已退出范围的功能。

用户确认：“还是之前的那种设计”“不用给用户那么复杂的信息，直接把首日算法定出来”“也要把首日日期定下来，我感觉就是初始化完成就行了”。

## 总览内容

热力图上方紧凑展示「已使用 X 天」「知识 X 条」「原始记录 X 条」。下方保留过去一年的知识热力图、近期动态、最近知识、项目入口和轻量连接状态。沿用浅蓝连续侧栏、白底、单色图标和最小 1200×820，不新增窄窗方案。

| 内容 | 产品含义 |
| --- | --- |
| 已使用 X 天 | 首次初始化完成当天为首日；首日计 1 天，之后按本地日历日期计算 |
| 知识 X 条 | 当前纳入 Memlane 的官方数据中，实际存在的有效知识总数 |
| 原始记录 X 条 | 相同范围内官方保存的独立会话与原始文档数量，同一来源不重复计入 |
| 知识热力图 | 当前保留知识按创建日期分布，表达每天新增知识；颜色深浅按当天数量变化 |
| 近期动态 | 官方实际记录的保存、处理、整理、检索／召回及其结果，按时间倒序展示 |

知识和原始记录都是当前总量，不承诺删除前的终身累计产量。热力图不使用调用次数、图节点数或操作成功数替代新增知识数，也不另存历史知识副本保持旧数字。

全局统计包含已关联项目与通用知识，同一官方数据组只计一次，排除代码专用及未纳入客户端的系统／测试数据组。选择热力图日期只改变下方的知识回顾，不改变顶部三项数字。

## 首日

首次初始化完成时保存完成时间和当日本地日期，之后重启、升级、重配模型、调整项目或重新经过配置流程均不覆盖。使用天数为本地今天与首日的日期差加 1。

现有安装若没有首日记录，在本功能接入后首次完成初始化就绪确认时写入当天；不猜测历史日期，不取最早知识或活动日期。界面只显示「已使用 X 天」，不增加首日算法或迁移说明。

## 阅读与反馈

点击有知识的日期，查看当天新增的知识，再进入既有阅读页；清除日期选择后恢复最近知识。近期动态如有可靠对象关联，可进入对应内容；无关联则只显示事件，不伪造跳转。

首次读取显示占位。成功读到空结果才显示 0；失败保留本次会话内上次有效结果并提供简短重试提示，不把失败显示成 0。缺少可靠数据的部分明确不可用，不阻塞其他模块阅读。

## 实施边界

Cognee 保持唯一内容源，Memlane 负责只读聚合和 Native 呈现。只持久化首日等必要客户端状态，不新增永久活动库、知识副本、重复索引、模型任务或后台调度。

本轮仅编写文档。后续实施须完成官方全量分页、来源去重、知识创建时间核对和实际 Native 对照，具体见配套规格与技术方案。已有交付报告与缺陷计数不改写。
